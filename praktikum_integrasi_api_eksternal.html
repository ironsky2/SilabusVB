Laboratorium Integrasi API Eksternal & Berbayar:
Dari API Publik Gratis ke Aplikasi AI "Asisten Aduan"

Panduan praktikum terpadu bagi pemula non-IT untuk membangun aplikasi web live yang mengonsumsi data API publik gratis ExchangeRate, menguji fungsionalitas di browser, melakukan debugging Console DevTools, mengamankan API key OpenWeather & Gemini AI, menabrak rate limit 429, serta memasang 5 sistem pengaman biaya operasional.

⏱️ Durasi Praktikum: 90 – 120 Menit
🌐 Modul 1: API Kurs (Gratis) & Cuaca (API Key)
🤖 Modul 2: API AI Berbayar / Free Tier (Asisten Aduan)
🛡️ Proteksi: Penanganan Error 429 & Pengaman Biaya
🛠️ Modul 1: Setup & Kurs Langkah 1: Prompt Kurs Langkah 2: Uji Browser Langkah 3: Iterasi Dropdown Langkah 4: Debug Console F12 Langkah 5: API Key Cuaca 🤖 Modul 2: Asisten Aduan AI 🛠️ Persiapan Kunci AI Tahap 1: Tampilan Dummy Tahap 2: Sambung API AI Tahap 3: Error & Biaya Rp Tahap 4: Sabotase Error 429 Tahap 5: 5 Pengaman Biaya 📊 Lembar Kalkulasi Biaya 💡 Latihan Mandiri 📑 Bank Prompt Ekstra 🔍 Troubleshooting ✅ Checklist & Rubrik

🎯 Alur Kerja Praktikum Integrasi API Komprehensif

Praktikum ini terbagi menjadi dua level progresif: Level 1 membangun fondasi dengan API publik gratis tanpa kunci, lalu Level 2 menaikkan keahlian ke integrasi API AI berbayar dengan manajemen kunci aman, mitigasi error 429, dan kalkulasi tagihan.

LEVEL 1: Integrasi API Publik Gratis & Debugging Console

Membangun Web Kurs Mata Uang Real-Time & Widget Cuaca OpenWeatherMap

🌐
🛠️

Tahap Persiapan — Lingkungan Kerja & Endpoint API

Mempersiapkan folder proyek lokal dan endpoint API gratis sebelum mulai menulis prompt.

📋 Checklist Persiapan Sebelum Memulai

  • Buka Endpoint Publik Gratis: Endpoint yang kita gunakan tidak memerlukan registrasi ataupun API key: https://open.er-api.com/v6/latest/USD

01

Langkah 1 — Prompt Awal: Kerangka Aplikasi Kurs Mata Uang

Meminta AI membangun halaman web single-file dengan integrasi live API.

Part A · Instruksi & Sasaran

Kita akan meminta AI membuat halaman web bernama "Kurs Mata Uang Hari Ini" yang langsung melakukan fetching ke endpoint open.er-api.com saat dibuka, menampilkan kurs USD ke IDR, EUR, JPY, dan SGD, serta memiliki tombol Refresh manual.

Part B · Master Prompt AI Siap Pakai

🤖 PROMPT 1: KERANGKA APLIKASI KURS MATA UANG 
Saya pemula, belum pernah coding sama sekali. Saya ingin membuat halaman web sederhana bernama "Kurs Mata Uang Hari Ini" menggunakan HTML, CSS, dan JavaScript polos (tanpa framework), dalam satu file HTML saja.

Halaman ini harus:
1. Mengambil data kurs mata uang secara real-time dari API gratis ini:
   https://open.er-api.com/v6/latest/USD
   (tidak perlu API key)
2. Menampilkan kurs USD terhadap IDR, EUR, JPY, dan SGD dalam bentuk kartu-kartu yang rapi dan modern.
3. Ada tombol "Refresh" untuk mengambil data terbaru.
4. Menampilkan animasi/pesan loading saat data sedang diambil, dan pesan yang ramah jika terjadi error (misalnya koneksi internet bermasalah).

Tolong:
- Tulis kode lengkap dalam satu file HTML.
- Beri komentar di setiap bagian kode dengan bahasa yang mudah dipahami orang non-programmer.
- Jelaskan langkah demi langkah cara menyimpan dan membuka file ini di browser.

Part C · Output & Verifikasi Kesiapan

✅ Output yang Diharapkan AI memberikan satu blok kode utuh. Simpan kode tersebut dengan nama index.html di dalam folder kurs-mata-uang.
⚠️ Kesalahan Umum Menyimpan dengan ekstensi index.html.txt karena Notepad otomatis menambahkan .txt. Pastikan tipe file saat Save As adalah "All Files (*.*)".

Memverifikasi aliran data dari server API eksternal ke layar laptop Anda.

  • Amati apakah angka kurs muncul (misal: 1 USD = Rp 16.000+).
  • Klik tombol Refresh dan pastikan status memuat ulang berjalan lancar tanpa membuat halaman crash.

Langkah 3 — Prompt Lanjutan: Menambahkan Fitur Dropdown & Timestamp

Melatih teknik iterasi bertahap pada kode yang sudah berjalan.

Part A · Skenario Penambahan Fitur

Aplikasi dasar sudah berhasil. Sekarang kita ingin pengguna bisa memilih mata uang asal (misal: ingin melihat dari IDR, EUR, atau JPY) serta menampilkan waktu pembaruan terakhir data (time_last_update_utc).

Part B · Master Prompt AI Siap Pakai

🤖 PROMPT 2: ITERASI DROPDOWN & TIMESTAMP UPDATE 
Aplikasi kurs mata uang saya sudah berjalan dengan baik. Sekarang saya ingin menambahkan beberapa fitur baru:

1. Dropdown pilihan untuk memilih mata uang asal (bukan hanya USD), pilihannya: USD, IDR, EUR, JPY, SGD.
2. Saat mata uang asal diganti di dropdown, data kurs otomatis diambil ulang dari API dengan endpoint dinamis:
   https://open.er-api.com/v6/latest/{KODE_MATA_UANG}
3. Tampilkan waktu terakhir data di-update (ambil dari field "time_last_update_utc" pada response JSON API) di bagian bawah kartu.

Tolong perbarui kode saya (saya lampirkan kode lengkap saat ini di bawah) dan jelaskan bagian mana saja yang Anda modifikasi agar saya paham:

[TEMPEL KODE index.html KAMU DI SINI]

Part C · Output & Verifikasi Kesiapan

✅ Output yang Diharapkan Saat Anda memilih mata uang "EUR" di dropdown, halaman secara otomatis mengirim request ke endpoint .../latest/EUR dan memperbarui nilai kurs secara instan.
⚠️ Kesalahan Umum Lupa menempelkan kode lama di bagian [TEMPEL KODE ...], sehingga AI membuat ulang dengan desain yang berbeda dari versi awal Anda.

Langkah 4 — Prompt Debugging: Simulasi Error & Console Browser

Keahlian paling krusial bagi Vibe Coder: Membuka DevTools dan meminta AI menyelesaikan masalah.

Part A · Cara Membuka Console Browser (F12)

Ketika aplikasi web tidak menampilkan data (hanya berputar di status "Loading..."), informasi penyebab error sebenarnya tercatat di Console Browser:

  • Klik kanan di mana saja pada halaman website di browser, lalu pilih Inspect (atau tekan tombol keyboard F12).
  • Pilih tab Console di bagian atas panel Developer Tools.
  • Perhatikan teks berwarna merah (misal: Failed to load resource: net::ERR_NAME_NOT_RESOLVED atau TypeError: Failed to fetch). Salin teks merah tersebut!

Part B · Master Prompt Debugging

🛠️ PROMPT 3: DEBUGGING ERROR INTEGRASI API 
Aplikasi kurs mata uang saya tidak menampilkan data kurs, hanya muncul tulisan "Loading..." yang tidak pernah berubah menjadi data.

Yang sudah saya periksa:
- Koneksi internet saya aktif dan lancar.
- Saya membuka file index.html langsung di Google Chrome.

Ini pesan error berwarna merah yang muncul di tab Console browser saya:
[TEMPEL PESAN ERROR DARI CONSOLE DI SINI]

Ini kode index.html saya saat ini:
[TEMPEL KODE index.html LENGKAP DI SINI]

Tolong jelaskan kemungkinan penyebab error tersebut dengan bahasa yang mudah dipahami pemula, dan berikan kode perbaikannya secara lengkap.
✅ Solusi AI AI akan mendiagnosis apakah masalah berasal dari typo URL, kesalahan membaca struktur JSON, atau aturan CORS, lalu memberikan perbaikan kode yang tepat.
⚠️ Jangan Lakukan Ini Hanya memberi prompt *"Aplikasi saya error tolong benerin"* tanpa menyertakan pesan error console dan kode yang sedang dipakai.

Langkah 5 — Integrasi API yang Membutuhkan Kunci Rahasia (API Key)

Studi kasus OpenWeatherMap dan edukasi keamanan kredensial.

Part A · Mengapa Butuh API Key?

Sebagian besar API komersial mewajibkan pendaftaran akun gratis untuk mendapatkan API Key pribadi. API key ini dikirimkan bersama request untuk menghitung kuota pemakaian Anda.

Part B · Master Prompt Pembuatan Widget Cuaca

🌦️ PROMPT 4: WIDGET CUACA DENGAN API KEY 
Saya sudah mendaftar akun gratis di OpenWeatherMap dan mendapatkan API key pribadi: [API_KEY_SAYA]

Saya ingin membuat halaman web widget cuaca sederhana yang menampilkan kondisi cuaca hari ini untuk kota Jakarta, menggunakan endpoint resmi berikut:
https://api.openweathermap.org/data/2.5/weather?q=Jakarta&appid=API_KEY_SAYA&units=metric

Tolong:
1. Buatkan kode lengkap dalam satu file HTML (HTML + CSS + JS).
2. Tampilkan nama kota, suhu saat ini (°C), ikon kondisi cuaca, dan tingkat kelembapan dalam bentuk kartu modern yang elegan.
3. PENTING: Jelaskan kepada saya cara terbaik menjaga keamanan API key ini agar tidak disalahgunakan orang lain jika suatu saat nanti proyek ini saya unggah ke GitHub atau internet publik.
🔐 Edukasi Keamanan Kunci API Key = Kunci Rumah Anda. Jangan pernah mengunggah file kode yang berisi API key asli ke repositori publik di GitHub. Gunakan file .env jika menggunakan backend / server.
⚠️ Risiko Kunci Bocor Jika API key berbayar bocor ke publik, orang asing bisa menghabiskan kuota atau menagih biaya kartu kredit Anda!

Studi Kasus Pemrosesan Teks Bebas, Penanganan Error 429, & 5 Sistem Pengaman Biaya

🎯

Studi Kasus: Aplikasi "Asisten Aduan Masyarakat"

Membangun aplikasi otomatisasi yang meringkas teks bebas, menentukan kategori topik, dan mengukur tingkat urgensi.

Masalah Nyata: Petugas pelayanan publik menerima puluhan teks aduan warga setiap hari dengan bahasa bebas yang panjang dan bertele-tele. Membaca satu per satu memakan waktu berjam-jam.

Solusi yang Dibangun: Halaman web di mana petugas menempelkan teks aduan → menekan tombol "Proses" → AI mengembalikan 3 hasil instan: Ringkasan Satu Kalimat, Kategori Layanan, dan Tingkat Urgensi (Rendah/Sedang/Tinggi).

🛡️
Rumus Emas K-T-B-H & 3 Kalimat Wajib:
Setiap prompt di modul ini menggunakan formula Konteks – Tugas – Batasan – Hasil serta menyertakan kalimat pengaman:
• Saya BUKAN programmer. Gunakan bahasa Indonesia sederhana.
• Jelaskan singkat apa yang akan kamu lakukan SEBELUM menulis kode.
• Jangan menjalankan perintah yang menghapus file atau membocorkan kredensial.
🔑

Tahap Persiapan — Mengamankan Kunci Akses AI & Mengecek Jatah Kuota Gratis

Langkah demi langkah memperoleh kredensial resmi Gemini API, menyimpannya di Notepad lokal, dan membaca meteran kuota.

Part A · Langkah Pengambilan Kunci & Penyimpanan Aman

  • Buka Portal Resmi AI Studio: Buka tautan aistudio.google.com/apikey menggunakan akun Google Anda.
  • Buat Kunci Baru: Klik tombol Create API Key → pilih proyek default → klik salin (copy) deretan karakter kunci unik yang muncul.
  • Amankan Sementara di Notepad Lokal: Tempelkan kunci tersebut ke dalam aplikasi Notepad di komputer Anda. (Dilarang keras menempelkan kunci ke chat WhatsApp, Telegram, atau dokumen publik!)
  • Periksa & Catat Jatah Kuota: Di halaman dashboard yang sama, periksa batas kuota gratis yang Anda miliki hari ini:
    • RPM (Request Per Minute): Batas frekuensi panggilan per menit (misal: 15 request/menit).
    • RPD (Request Per Day): Batas kuota total panggilan per hari (misal: 1.500 request/hari).
    • TPM (Tokens Per Minute): Batas volume kata yang diproses per menit.
💡
Tips Penting — Jika Muncul Peringatan Akun Dibatasi:
Jika email kantor, instansi, atau kampus Anda memblokir akses ke Google AI Studio karena kebijakan keamanan internal organisasi (admin policy), beralihlah menggunakan akun Google pribadi (Gmail biasa). Akun pribadi selalu memiliki akses langsung ke Free Tier pengembang tanpa batasan administratif kantor.
✅ Keterampilan Kunci yang Terbentuk Anda mampu membaca dashboard pemakaian sendiri dan memahami bahwa API Key adalah kartu identitas yang menempel pada kuota Anda.
⚠️ Ritual Disiplin Keamanan Kunci yang Anda buat untuk latihan ini wajib dihapus / dicabut (revoked) di dashboard segera setelah kelas selesai!

Tahap 2 — Sambungkan ke API AI Sungguhan

Mengganti data dummy dengan integrasi model kecerdasan buatan sesungguhnya.

Jalur Utama (Disarankan) — Server Backend Kecil & File .env

Ini adalah praktik standar industri: API Key disimpan aman di file .env di dalam server lokal Node.js, bukan di file HTML yang bisa diintip pengunjung browser.

🤖 PROMPT AI-2 (JALUR UTAMA): BACKEND SERVER & ENV AMAN 
Saya BUKAN programmer. Gunakan bahasa Indonesia sederhana.
Jelaskan singkat apa yang akan kamu lakukan sebelum menulis kode.

KONTEKS:
Lanjutkan aplikasi index.html yang tadi. Sekarang saya ingin data palsu diganti dengan panggilan ke API AI yang sesungguhnya.

BATASAN KEAMANAN (Paling Penting):
- API key TIDAK BOLEH ada di file yang dibuka browser.
- Simpan API key di file .env
- Buat file .gitignore yang mengabaikan .env
- Sebelum menulis kode, periksa dulu nama model yang MASIH AKTIF di dokumentasi resmi (misal: gemini-1.5-flash / gemini-2.5-flash). Jangan mengarang nama model.

TUGAS:
1. Buat server kecil dengan Node.js yang:
   - menyajikan index.html
   - punya satu alamat POST /api/proses
   - alamat itu menerima teks aduan dari halaman, memanggil API AI, lalu mengembalikan JSON berisi tiga isian: ringkasan (1 kalimat), kategori, dan urgensi
2. Minta AI menjawab dalam format JSON murni agar mudah ditampilkan.
3. Ubah index.html agar tombol "Proses" memanggil /api/proses, bukan data palsu.

HASIL YANG SAYA INGINKAN:
- Tuliskan langkah persis yang harus saya ketik di terminal untuk menjalankannya.
- Beri tahu di mana saya menempelkan API key saya.
- Beri tahu cara menguji bahwa sambungannya sudah berhasil.

Jalur Cadangan (Plan B) — Jika Komputer Mengalami Masalah Node.js

⚠️
Peringatan Tegas: Cara ini menempelkan API key langsung di file browser. HANYA boleh dipakai untuk latihan mandiri di laptop sendiri, DILARANG KERAS diunggah ke internet/GitHub, dan kunci WAJIB DIHAPUS setelah latihan!
🤖 PROMPT AI-2B (PLAN B): DIRECT BROWSER CALL DENGAN WARNING 
Saya BUKAN programmer. Gunakan bahasa Indonesia sederhana.

Node.js tidak bisa saya jalankan di laptop saya. Untuk latihan hari ini saja, ubah agar index.html memanggil API AI langsung dari browser, dengan API key saya tempel di satu variabel di baris paling atas file.

Saya sadar cara ini tidak aman dan hanya untuk latihan lokal sementara.
Tambahkan komentar peringatan besar di atas variabel itu bahwa file ini tidak boleh dibagikan atau diunggah ke internet.

Sisanya sama: minta AI menjawab dalam format JSON berisi ringkasan, kategori, dan urgensi dari teks aduan yang dimasukkan pengguna.
✅ Momen Panggilan API Berbayar Pertama Satu teks aduan asli diproses → Hasil ringkasan riil muncul! Buka dashboard AI Studio Anda: Perhatikan angka kuota/grafik pemakaian yang bertambah 1 transaksi.
⚠️ Model Deprecated Jika muncul error 404 Model Not Found, minta AI mengecek nama model terkini (misal: gemini-1.5-flash).

Tahap 3 — Penanganan Error Ramah Awam & Indikator Biaya Rupiah

Membangun antarmuka yang transparan biaya dan ramah terhadap pengguna non-teknis.

Part B · Master Prompt 3 (Error Awam & Biaya Rp)

🤖 PROMPT AI-3: PESAN ERROR JELAS & KALKULATOR BIAYA 
Sekarang buat aplikasi Asisten Aduan ini layak dipakai oleh pengguna umum.

TUGAS 1 — PESAN ERROR BAHASA INDONESIA YANG RAMAH:
Ganti semua pesan error teknis mentah dengan kalimat bahasa Indonesia yang jelas untuk kondisi berikut:
- API key salah, kosong, atau sudah dicabut
- Kuota atau batas kecepatan habis (error 429)
- Komputer offline / tidak ada koneksi internet
- Teks aduan masih kosong saat tombol ditekan
Setiap pesan error harus memberi tahu tindakan apa yang harus dilakukan pengguna berikutnya.

TUGAS 2 — INDIKATOR PENGGUNAAN TOKEN & BIAYA RUPIAH:
Setelah setiap pemrosesan berhasil, tampilkan di bawah kartu hasil:
- Jumlah Token Masuk (Input)
- Jumlah Token Keluar (Output)
- Estimasi Biaya dalam Rupiah (Rp)
Buat variabel harga per 1 juta token dan kurs USD ke IDR di bagian atas file dengan komentar agar saya bisa mengisinya sendiri. JANGAN mengarang angka tagihan.

TUGAS 3 — STATE LOADING & ANTI-DOUBLE CLICK:
Saat menunggu jawaban API, ubah tombol menjadi "Sedang Menganalisis...", beri animasi loading, dan NONAKTIFKAN (disable) tombol tersebut agar pengguna tidak menekan berkali-kali.
💡
Catatan Penting Pengajar: Angka estimasi Rupiah yang muncul di layar adalah kalkulasi internal berdasarkan harga unit yang Anda setel di kode — bukan membaca tagihan resmi bank. Tagihan riil tetap mengacu pada dashboard resmi penyedia API!

Tahap 4 — Sengaja Dirusak: Simulasi Sabotase & Error 429

Merasakan secara langsung bagaimana sistem bereaksi saat kuota habis atau kunci tidak valid.

Part A · Tiga Skenario Sabotase Terkendali

# Tindakan Sabotase Peserta Respon yang Seharusnya Muncul Pelajaran Berharga yang Didapat
1 Hapus 3 karakter terakhir dari API key di file .env, lalu jalankan. Muncul kartu merah: "Kunci API tidak valid. Periksa kembali API key Anda." Kunci salah tidak membuat aplikasi hancur lebur jika ditangani dengan baik.
2 Kembalikan kunci benar, lalu klik tombol Proses 15–20 kali secepat mungkin! Muncul pesan Error 429: "Terlalu banyak permintaan! Kuota kecepatan habis. Silakan tunggu 1 menit." Inilah rasanya kuota habis (Rate Limit 429). Di akun berbayar komersial, menekan 20 kali berarti membayar 20 kali lipat!
3 Kosongkan kotak teks lalu tekan tombol Proses. Muncul peringatan: "Teks aduan belum diisi. Masukkan teks sebelum memproses." Validasi input di browser mencegah panggilan API sia-sia yang tetap memotong saldo Anda.

Part B · Pola Baku Prompt Perbaikan Error Seumur Hidup

🛠️ PROMPT AI-4: POLA BAKU INVESTIGASI ERROR 
Saya mendapat pesan error berikut saat menjalankan aplikasi saya:

[TEMPEL PESAN ERROR PERSIS SEPERTI YANG MUNCUL DI LAYAR / CONSOLE]

Ini kode aplikasi saya saat ini:
[TEMPEL KODE index.html / server.js]

Tolong:
1. Jelaskan dalam bahasa Indonesia sederhana apa penyebab pasti dari error ini.
2. Sebutkan kemungkinan penyebabnya, urutkan dari yang paling sering terjadi.
3. Berikan kode perbaikannya secara lengkap.
4. Jelaskan cara saya menguji bahwa perbaikan ini sudah 100% berhasil.

Tahap 5 — Memasang 5 Sistem Pengaman Biaya (Cost Guardrails)

Fitur wajib sebelum aplikasi apa pun dirilis atau dibagikan ke pengguna umum.

Part B · Master Prompt 5 (5 Pengaman Biaya)

🛡️ PROMPT AI-5: 5 SISTEM PENGAMAN BIAYA KELAS PRODUKSI 
Tambahkan 5 sistem pengaman biaya berikut ke aplikasi Asisten Aduan saya, dan beri penjelasan singkat di mana penghematan terjadi untuk setiap fitur:

1. BATAS KARAKTER MASUKAN:
   Batasi teks aduan maksimal 2.000 karakter. Tampilkan indikator sisa karakter di bawah kotak teks (misal: "Sisa 1.850 karakter"). Kunci input jika melewati batas.

2. BATASI PANJANG JAWABAN (MAX OUTPUT TOKEN):
   Setel parameter max_output_tokens ke maksimal 300 token di konfigurasi API. Jelaskan kenapa memotong token keluar menghemat biaya terbesar.

3. MEMORI PENYIMPANAN SEMENTARA (IN-MEMORY CACHING):
   Jika pengguna memproses teks aduan yang PERSIS SAMA dengan yang baru saja diproses, ambil hasil dari memori browser/server dan JANGAN memanggil API ulang. Berikan label hijau: "⚡ Diambil dari simpanan cache (Tanpa Biaya API)".

4. BATAS MAKSIMAL SESI (SESSION LIMITER):
   Batasi maksimal 20 panggilan API per sesi pengguna. Setelah mencapai 20 panggilan, kunci tombol dan tampilkan: "Batas pemrosesan sesi tercapai untuk keamanan biaya."

5. TOTAL BIAYA KUMULATIF:
   Tampilkan total akumulasi biaya rupiah yang telah digunakan sejak halaman web dibuka.
💰
Analisis Penghematan Biaya: Dari kelima fitur pengaman di atas, kombinasi Nomor 2 (Max Output Token) dan Nomor 3 (In-Memory Cache) memberikan efisiensi anggaran hingga 70–90%! Token output adalah komponen paling mahal, dan caching memangkas panggilan duplikat menjadi 0 Rupiah.

Lembar Kalkulasi Biaya Operasional (Simulasi 1.000 Aduan/Bulan)

Latihan numerik untuk memproyeksikan anggaran nyata sebelum aplikasi di-deploy.

Mari hitung estimasi biaya operasional jika aplikasi "Asisten Aduan" digunakan oleh satu instansi/kelurahan dengan rata-rata 1.000 laporan aduan per bulan:

No Komponen Perhitungan Rumus / Formula Estimasi Nilai
a Token masuk per aduan ± Panjang teks aduan ÷ 4 karakter ~ 250 Token
b Token keluar per aduan ± Panjang jawaban ringkasan & kategori ~ 100 Token
c Total Token Masuk per Bulan 250 token × 1.000 aduan 250.000 Token
d Total Token Keluar per Bulan 100 token × 1.000 aduan 100.000 Token
e Harga Token Masuk (per 1 Juta Token) Lihat halaman Pricing model resmi ± $0.075 USD / 1M
f Harga Token Keluar (per 1 Juta Token) Lihat halaman Pricing model resmi ± $0.30 USD / 1M
g Biaya Masuk Bulanan (250.000 ÷ 1.000.000) × $0.075 $0.01875 USD
h Biaya Keluar Bulanan (100.000 ÷ 1.000.000) × $0.30 $0.03000 USD
i Total Biaya USD Bulanan g + h $0.04875 USD
j Kurs USD ke IDR Kurs acuan hari ini Rp 16.200 / USD
k TOTAL BIAYA OPERASIONAL BULANAN Total USD × Kurs IDR Rp 789,75 / Bulan (~ Rp 800)
💡
Insight Mengejutkan: Untuk 1.000 aduan per bulan dengan model ringan (Flash), biayanya bahkan di bawah Rp 1.000 per bulan (dan sepenuhnya gratis jika masih dalam batas Free Tier). Namun jika aplikasi diserang bot looping tanpa pengaman dan volume naik 100.000x, tagihan bisa melonjak menjadi puluhan juta Rupiah jika memakai pay-as-you-go tanpa spend limit!

Bagian 4 — Tantangan Latihan Mandiri

Tantangan A: Generator Kutipan Motivasi Harian (API Publik)

Gunakan API https://api.quotable.io/random untuk membuat kartu kutipan inspiratif acak beserta nama penulisnya, dilengkapi tombol "Kutipan Baru".

Tantangan B: Ensiklopedia Pencarian Negara (API Publik)

Gunakan API https://restcountries.com/v3.1/name/{nama_negara} untuk menampilkan bendera negara, ibu kota, populasi, dan mata uang saat pengguna mengetik nama negara.

Ganti studi kasus Asisten Aduan dengan kebutuhan spesifik di kantor/pekerjaan Anda sendiri (misal: pengklasifikasi disposisi surat dinas, pembuat notulen rapat, atau penilai kelengkapan berkas lamaran).

Bank Prompt Tambahan yang Sering Dibutuhkan

Prompt penyelamat untuk mengendalikan perilaku agen AI saat pengerjaan proyek.

A-1: MEMAKSA AGEN MENJELASKAN SEBELUM MENULIS KODE 
Sebelum menulis atau mengubah kode apa pun, jelaskan terlebih dahulu dalam maksimal 4 kalimat bahasa Indonesia sederhana: apa persisnya yang akan kamu ubah, di file mana, dan apa risiko perubahannya. Tunggu saya membalas "Lanjut" baru kamu boleh menuliskan kode.
A-2: KEMBALI KE KONDISI TERAKHIR YANG BERFUNGSI (REVERT) 
Perubahan terakhir membuat aplikasi saya error dan tidak bisa dibuka. Tolong kembalikan kode ke kondisi persis seperti sebelum perubahan terakhir, lalu jelaskan apa yang salah. Jangan menambahkan fitur baru apa pun saat ini.
A-3: AUDIT KEAMANAN KEBOCORAN KUNCI SEBELUM SHARE / PUSH 
Periksa seluruh file di proyek ini. Apakah ada API key, kata sandi, token rahasia, atau informasi sensitif yang tertulis langsung di dalam file kode atau file yang berpotensi ikut terunggah ke internet? Sebutkan nama file dan nomor barisnya. JANGAN tampilkan teks kuncinya di jawabanmu.
A-4: MENERJEMAHKAN DOKUMENTASI API KE BAHASA AWAM 
Saya menempelkan potongan dokumentasi API di bawah ini. Saya bukan programmer. Jelaskan dalam bahasa Indonesia sederhana:
1. Apa data yang harus saya kirim (Request)?
2. Apa data yang akan saya terima balik (Response)?
3. Bagaimana layanan ini menghitung biaya / tagihan?
4. Batas kuota apa saja yang berlaku?

Tabel Troubleshooting & Diagnosa Mandiri

Solusi cepat saat Anda menghadapi kendala teknis.

Gejala / Pesan Error Kemungkinan Penyebab Utama Tindakan Perbaikan Tercepat
401 Unauthorized / Invalid API Key Kunci salah salin, ada spasi di ujung, atau sudah dicabut di dashboard. Salin ulang kunci menggunakan tombol Copy di dashboard penyedia API.
429 Too Many Requests / Quota Exceeded Batas kecepatan per menit (RPM) atau kuota harian habis terpakai. Tunggu jeda 1 menit, kurangi frekuensi klik, atau aktifkan fitur caching.
404 Not Found / Model Not Found Nama model AI lama sudah dipensiunkan oleh Google/OpenAI. Minta agen AI memeriksa nama model aktif resmi di dokumentasi terkini.
Failed to Fetch / CORS Error di Browser Browser memblokir request langsung ke server eksternal karena kebijakan keamanan. Pindahkan pemanggilan API ke server backend Node.js (Jalur Utama).
Tampilan loading berputar tanpa henti Terjadi kesalahan JavaScript atau sintaks JSON tidak valid. Buka tab Console (F12), salin teks error merah, dan kirim ke Prompt AI-4.
