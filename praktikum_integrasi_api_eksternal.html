Laboratorium Integrasi API Eksternal:
Membangun Web Kurs Mata Uang & API Key

Panduan langkah demi langkah bagi pemula non-IT untuk membuat aplikasi web live yang mengonsumsi data API publik gratis ExchangeRate, menguji fungsionalitas, menambahkan fitur interaktif bertahap, melakukan debugging lewat Console Browser, dan mengamankan API key.

⏱️ Durasi Praktikum: ± 90 - 120 Menit
🌐 API Target: open.er-api.com (Gratis tanpa key)
🌦️ Studi Lanjutan: OpenWeatherMap (API Key Security)
💻 File Output: index.html (Single-File App)
🛠️ Tahap Persiapan Langkah 1: Prompt Awal Kurs Langkah 2: Uji Hasil Langkah 3: Iterasi Fitur Langkah 4: Debugging Console Langkah 5: API Key & Cuaca Bagian 3: Latihan Mandiri Bagian 4: Checklist Evaluasi

🎯 Alur Kerja Praktikum Vibe Coding Hari Ini

Kita akan mempraktikkan alur kerja profesional: Mulai dari tahap persiapan, pengujian browser, iterasi fitur baru, investigasi error lewat Console DevTools, hingga manajemen kunci rahasia API Key.

[ 🛠️ TAHAP PERSIAPAN: Setup Folder ] ---> [ LANGKAH 1: Prompt AI Kurs Dasar ] ---> [ LANGKAH 2: Live Browser Test ] | v [ LANGKAH 5: API Key Cuaca ] <--- [ LANGKAH 4: Debug Console ] <--- [ LANGKAH 3: Fitur Dropdown & Update ]
✨ Kunci Sukses Praktikum: Setiap prompt AI di bawah ini telah dirancang dengan format 5 elemen. Salin langsung menggunakan tombol copy, tempel ke AI assistant Anda (Claude, ChatGPT, Antigravity AI, Cursor), dan lihat bagaimana aplikasi Anda terbentuk!
🛠️

Tahap Persiapan — Lingkungan Kerja & Endpoint API

Mempersiapkan folder proyek lokal dan endpoint API gratis sebelum mulai menulis prompt.

📋 Checklist Persiapan Sebelum Memulai

  • Buka Endpoint Publik Gratis: Endpoint yang kita gunakan tidak memerlukan registrasi ataupun API key: https://open.er-api.com/v6/latest/USD
  • Buka AI Coding Assistant: Siapkan tab browser dengan ChatGPT, Claude.ai, atau Antigravity AI IDE.
  • Siapkan Folder Proyek: Buat sebuah folder baru di komputer Anda dengan nama kurs-mata-uang. Di dalam folder inilah nanti file index.html akan disimpan.
01

Langkah 1 — Prompt Awal: Kerangka Aplikasi Kurs Mata Uang

Meminta AI membangun halaman web single-file dengan integrasi live API.

Part A · Instruksi & Sasaran

Kita akan meminta AI membuat halaman web bernama "Kurs Mata Uang Hari Ini" yang langsung melakukan fetching ke endpoint open.er-api.com saat dibuka, menampilkan kurs USD ke IDR, EUR, JPY, dan SGD, serta memiliki tombol Refresh manual.

Part B · Master Prompt AI Siap Pakai

🤖 PROMPT 1: KERANGKA APLIKASI KURS MATA UANG 
Saya pemula, belum pernah coding sama sekali. Saya ingin membuat halaman web sederhana bernama "Kurs Mata Uang Hari Ini" menggunakan HTML, CSS, dan JavaScript polos (tanpa framework), dalam satu file HTML saja.

Halaman ini harus:
1. Mengambil data kurs mata uang secara real-time dari API gratis ini:
   https://open.er-api.com/v6/latest/USD
   (tidak perlu API key)
2. Menampilkan kurs USD terhadap IDR, EUR, JPY, dan SGD dalam bentuk kartu-kartu yang rapi dan modern.
3. Ada tombol "Refresh" untuk mengambil data terbaru.
4. Menampilkan animasi/pesan loading saat data sedang diambil, dan pesan yang ramah jika terjadi error (misalnya koneksi internet bermasalah).

Tolong:
- Tulis kode lengkap dalam satu file HTML.
- Beri komentar di setiap bagian kode dengan bahasa yang mudah dipahami orang non-programmer.
- Jelaskan langkah demi langkah cara menyimpan dan membuka file ini di browser.

Part C · Output & Verifikasi Kesiapan

✅ Output yang Diharapkan AI memberikan satu blok kode utuh. Simpan kode tersebut dengan nama index.html di dalam folder kurs-mata-uang.
⚠️ Kesalahan Umum Menyimpan dengan ekstensi index.html.txt karena Notepad otomatis menambahkan .txt. Pastikan tipe file saat Save As adalah "All Files (*.*)".
02

Langkah 2 — Menguji Hasil Aplikasi di Web Browser

Memverifikasi aliran data dari server API eksternal ke layar laptop Anda.

Part A · Langkah Pengujian

  • Buka file index.html dengan cara double-click atau drag-and-drop file tersebut ke Google Chrome / Microsoft Edge.
  • Amati apakah angka kurs muncul (misal: 1 USD = Rp 16.000+).
  • Klik tombol Refresh dan pastikan status memuat ulang berjalan lancar tanpa membuat halaman crash.
✅ Indikator Berhasil Kartu mata uang USD → IDR, EUR, JPY, dan SGD terisi nilai angka riil yang bersumber dari API publik.
⚠️ Jika Angka Kosong Pastikan laptop terhubung ke jaringan internet aktif, karena API membutuhkan koneksi untuk mengunduh data kurs terbaru.
03

Langkah 3 — Prompt Lanjutan: Menambahkan Fitur Dropdown & Timestamp

Melatih teknik iterasi bertahap pada kode yang sudah berjalan.

Part A · Skenario Penambahan Fitur

Aplikasi dasar sudah berhasil. Sekarang kita ingin pengguna bisa memilih mata uang asal (misal: ingin melihat dari IDR, EUR, atau JPY) serta menampilkan waktu pembaruan terakhir data (time_last_update_utc).

Part B · Master Prompt AI Siap Pakai

🤖 PROMPT 2: ITERASI DROPDOWN & TIMESTAMP UPDATE 
Aplikasi kurs mata uang saya sudah berjalan dengan baik. Sekarang saya ingin menambahkan beberapa fitur baru:

1. Dropdown pilihan untuk memilih mata uang asal (bukan hanya USD), pilihannya: USD, IDR, EUR, JPY, SGD.
2. Saat mata uang asal diganti di dropdown, data kurs otomatis diambil ulang dari API dengan endpoint dinamis:
   https://open.er-api.com/v6/latest/{KODE_MATA_UANG}
3. Tampilkan waktu terakhir data di-update (ambil dari field "time_last_update_utc" pada response JSON API) di bagian bawah kartu.

Tolong perbarui kode saya (saya lampirkan kode lengkap saat ini di bawah) dan jelaskan bagian mana saja yang Anda modifikasi agar saya paham:

[TEMPEL KODE index.html KAMU DI SINI]

Part C · Output & Verifikasi Kesiapan

✅ Output yang Diharapkan Saat Anda memilih mata uang "EUR" di dropdown, halaman secara otomatis mengirim request ke endpoint .../latest/EUR dan memperbarui nilai kurs secara instan.
⚠️ Kesalahan Umum Lupa menempelkan kode lama di bagian [TEMPEL KODE ...], sehingga AI membuat ulang dengan desain yang berbeda dari versi awal Anda.
04

Langkah 4 — Prompt Debugging: Simulasi Error & Console Browser

Keahlian paling krusial bagi Vibe Coder: Membuka DevTools dan meminta AI menyelesaikan masalah.

Part A · Cara Membuka Console Browser (F12)

Ketika aplikasi web tidak menampilkan data (hanya berputar di status "Loading..."), informasi penyebab error sebenarnya tercatat di Console Browser:

  • Klik kanan di mana saja pada halaman website di browser, lalu pilih Inspect (atau tekan tombol keyboard F12).
  • Pilih tab Console di bagian atas panel Developer Tools.
  • Perhatikan teks berwarna merah (misal: Failed to load resource: net::ERR_NAME_NOT_RESOLVED atau TypeError: Failed to fetch). Salin teks merah tersebut!

Part B · Master Prompt Debugging

🛠️ PROMPT 3: DEBUGGING ERROR INTEGRASI API 
Aplikasi kurs mata uang saya tidak menampilkan data kurs, hanya muncul tulisan "Loading..." yang tidak pernah berubah menjadi data.

Yang sudah saya periksa:
- Koneksi internet saya aktif dan lancar.
- Saya membuka file index.html langsung di Google Chrome.

Ini pesan error berwarna merah yang muncul di tab Console browser saya:
[TEMPEL PESAN ERROR DARI CONSOLE DI SINI]

Ini kode index.html saya saat ini:
[TEMPEL KODE index.html LENGKAP DI SINI]

Tolong jelaskan kemungkinan penyebab error tersebut dengan bahasa yang mudah dipahami pemula, dan berikan kode perbaikannya secara lengkap.
✅ Solusi AI AI akan mendiagnosis apakah masalah berasal dari typo URL, kesalahan membaca struktur JSON, atau aturan CORS, lalu memberikan perbaikan kode yang tepat.
⚠️ Jangan Lakukan Ini Hanya memberi prompt *"Aplikasi saya error tolong benerin"* tanpa menyertakan pesan error console dan kode yang sedang dipakai.
05

Langkah 5 — Integrasi API yang Membutuhkan Kunci Rahasia (API Key)

Studi kasus OpenWeatherMap dan edukasi keamanan kredensial.

Part A · Mengapa Butuh API Key?

Sebagian besar API komersial mewajibkan pendaftaran akun gratis untuk mendapatkan API Key pribadi. API key ini dikirimkan bersama request untuk menghitung kuota pemakaian Anda.

Part B · Master Prompt Pembuatan Widget Cuaca

🌦️ PROMPT 4: WIDGET CUACA DENGAN API KEY 
Saya sudah mendaftar akun gratis di OpenWeatherMap dan mendapatkan API key pribadi: [API_KEY_SAYA]

Saya ingin membuat halaman web widget cuaca sederhana yang menampilkan kondisi cuaca hari ini untuk kota Jakarta, menggunakan endpoint resmi berikut:
https://api.openweathermap.org/data/2.5/weather?q=Jakarta&appid=API_KEY_SAYA&units=metric

Tolong:
1. Buatkan kode lengkap dalam satu file HTML (HTML + CSS + JS).
2. Tampilkan nama kota, suhu saat ini (°C), ikon kondisi cuaca, dan tingkat kelembapan dalam bentuk kartu modern yang elegan.
3. PENTING: Jelaskan kepada saya cara terbaik menjaga keamanan API key ini agar tidak disalahgunakan orang lain jika suatu saat nanti proyek ini saya unggah ke GitHub atau internet publik.
🔐 Edukasi Keamanan Kunci API Key = Kunci Rumah Anda. Jangan pernah mengunggah file kode yang berisi API key asli ke repositori publik di GitHub. Gunakan file .env jika menggunakan backend / server.
⚠️ Risiko Kunci Bocor Jika API key berbayar bocor ke publik, orang asing bisa menghabiskan kuota atau menagih biaya kartu kredit Anda!
03

Bagian 3 — Tiga Tantangan Latihan Mandiri

Uji kemandirian Anda menyusun prompt integrasi API dari awal.

💡 Tantangan 1: Generator Kutipan Motivasi Harian

Gunakan API gratis https://api.quotable.io/random untuk menampilkan kartu kutipan inspiratif acak beserta nama penulisnya, dilengkapi tombol "Kutipan Baru".

🧠 Tantangan 2: Generator Fakta Unik Dunia

Gunakan API gratis https://uselessfacts.jsph.pl/api/v2/facts/random?language=en untuk menampilkan fakta trivia unik setiap kali tombol ditekan.

🌍 Tantangan 3: Ensiklopedia Pencarian Negara

Gunakan API https://restcountries.com/v3.1/name/{nama_negara} untuk menampilkan informasi negara (gambar bendera, ibu kota, jumlah populasi, dan mata uang resmi) saat pengguna mengetik nama negara di kotak pencarian.

Instruksi Pelaksanaan Latihan:

  • Tulis prompt awal sendiri menggunakan panduan Kerangka 5 Elemen dari Modul Teori.
  • Simpan dan jalankan hasilnya di browser.
  • Jika ada kendala/error, buka tab Console browser, salin pesan error, dan susun prompt debugging ke AI.
