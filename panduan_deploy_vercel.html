📘 Product Requirements Document (PRD) — Modul Praktikum

Laboratorium Deploy Vercel & Supabase:
Aplikasi Keluar dari Laptop ke Internet

Panduan praktikum terpadu 5 Fase bagi pemula non-IT untuk meluncurkan aplikasi web ke cloud hosting global Vercel dengan integrasi database Supabase PostgreSQL, otomasi CI/CD Git Push, brankas Environment Variables, dan penanganan error darurat.

🎯 Sasaran: URL Publik *.vercel.app
⚡ Otomasi: CI/CD via GitHub Push
🔐 Keamanan: Environment Variables Brankas
🤖 Metode: Copy-Paste Prompt ke AI Agent
🗺️ Peta Alur Deploy Fase A · Siapkan Laptop Fase B · GitHub Cloud Fase C · Vercel Hosting Fase D · Update Otomatis Fase E · Supabase DB 🆘 Prompt Darurat 📋 Checklist 100%

🗺️ Peta Arsitektur 5 Fase Perjalanan Deploy

Prinsip utama: "Tidak perlu pusing sintaks server yang rumit — pahami alurnya, salin prompt-nya ke AI!"

💡 Key Insight: Laptop Anda menulis kode (Fase A) ➔ GitHub menyimpan snapshot aman (Fase B) ➔ Vercel menyiarkan aplikasi ke seluruh dunia (Fase C) ➔ CI/CD update otomatis via git push (Fase D) ➔ Supabase mengelola database pengguna (Fase E).
A

Fase A · Siapkan Laptop & Folder Proyek

Pengecekan kesiapan sistem operasi, instalasi Git, dan penataan struktur folder sebelum kode dikirim.

📚 Part A · Teori Pedagogis & Mental Model
💡 Analogi Dapur Sebelum Memasak:

Sebelum mulai memasak untuk tamu undangan, kita periksa dulu apakah wajan, kompor, dan wadah piring sudah tersedia. Di tahap ini, kita memastikan alat pengirim (Git) sudah aktif di laptop dan file kode berada di folder yang tepat.

🤖 Part B · Master Prompts AI Siap Pakai
🟢 PROMPT A-1 · Cek Kesiapan Laptop

Gunakan di awal sesi untuk meminta AI memandu pengecekan Git di terminal.

Prompt AI (Antigravity / Cursor / Claude)
Halo! Saya adalah pemula yang sama sekali belum pernah coding atau deploy website. Hari ini saya ingin deploy website HTML saya ke internet menggunakan Vercel.

Tolong panduan saya untuk mengecek apakah laptop saya sudah siap:
1. Cara cek apakah Git sudah terinstall atau belum di Command Prompt/Terminal.
2. Link instalasi dan langkah mudah jika Git belum ada.

Sistem operasi saya: [Windows/Mac/Linux]

Berikan instruksi langkah demi langkah yang sangat sederhana tanpa istilah rumit.
🟢 PROMPT A-2 · Siapkan Folder Proyek
Prompt AI (Folder Setup)
Saya sudah punya kode website dalam bentuk file HTML dari AI. Sekarang saya perlu menyimpannya dengan benar di laptop saya sebelum upload ke GitHub.

Tolong panduan saya:
1. Cara membuat folder baru untuk proyek saya
2. Cara menyimpan file HTML saya di folder tersebut dengan nama `index.html`
3. Cara membuka folder tersebut di VS Code

Nama proyek saya: [TULIS NAMA PROYEK, contoh: fin-track-app]
Sistem operasi saya: [Windows/Mac/Linux]
✅ Part C · Output & Verifikasi Kesiapan
Output yang Diharapkan: Perintah git --version menampilkan nomor versi, dan file index.html terbuka rapi di browser lokal saat di-klik ganda.
Perangkap Pemula: Menyimpan file di Desktop tanpa folder wadah, atau menamai file dengan huruf besar (`Index.html`) yang bisa menyebabkan error di server Linux Vercel.
B

Fase B · Upload Kode ke GitHub (Cloud Storage)

Inisialisasi repository git, pembuatan commit pertama, dan pengiriman kode ke repository cloud GitHub.

📚 Part A · Teori Pedagogis & Mental Model
💡 Analogi Gudang Titip Koper di Bandara:

GitHub adalah gudang aman di awan (cloud). Kita menitipkan salinan koper proyek kita di sana agar platform hosting (Vercel) bisa mengambil dan menampilkannya ke internet kapan saja.

🤖 Part B · Master Prompts AI Siap Pakai
🟢 PROMPT B-1 · Buat Repository GitHub
Prompt AI (Buat Akun & Repo)
Saya belum pernah menggunakan GitHub sebelumnya. Saya perlu membuat akun GitHub dan menyiapkan sebuah repository (folder cloud) untuk menyimpan proyek website saya.

Tolong panduan saya langkah demi langkah untuk:
1. Mendaftar akun GitHub (jika belum punya)
2. Membuat repository baru yang bernama [NAMA PROYEK]
3. Mengatur repository sebagai Public (bukan Private)

Jelaskan apa yang harus saya klik dan apa yang harus saya lihat di layar.
🟢 PROMPT B-3 · Git Push Pertama
Prompt AI (Upload Push)
Saya sudah punya folder proyek di laptop dan repository kosong di GitHub bernama [NAMA REPOSITORY].

Tolong berikan panduan perintah terminal langkah demi langkah untuk:
1. Membuka Terminal di folder proyek saya
2. Inisialisasi Git (`git init`)
3. Menandai file (`git add .`)
4. Membuat snapshot commit (`git commit -m "first commit"`)
5. Menghubungkan ke remote repo GitHub (`git remote add origin ...`)
6. Mengirim file ke GitHub (`git push -u origin main`)

Username GitHub saya: [USERNAME GITHUB]
Nama repository: [NAMA REPOSITORY]
✅ Part C · Output & Verifikasi Kesiapan
Output yang Diharapkan: Halaman repository di `github.com/username/nama-repo` menampilkan daftar file `index.html` dan riwayat commit pertama.
Perangkap Pemula: Muncul popup login yang menolak password biasa (Gunakan Personal Access Token atau GitHub CLI untuk login).
C

Fase C · Deploy ke Vercel Cloud Server

Menghubungkan akun GitHub ke Vercel dan melakukan deployment otomatis ke jaringan server global.

📚 Part A · Teori Pedagogis & Mental Model
💡 Analogi Membuka Toko di Mal Pusat Kota:

Jika `localhost` adalah toko di garasi pribadi, maka Vercel adalah membuka etalase toko di mal global dengan penjaga 24 jam dan sertifikat keamanan (HTTPS) gratis.

🤖 Part B · Master Prompts AI Siap Pakai
🟢 PROMPT C-2 · Import Proyek & Deploy
Prompt AI (Vercel Deploy)
Akun Vercel saya sudah terhubung ke GitHub. Sekarang saya ingin men-deploy repository GitHub saya bernama [NAMA REPOSITORY] yang berisi file website.

Tolong panduan saya langkah demi langkah untuk:
1. Menemukan tombol menambah proyek baru di Vercel (Add New... → Project)
2. Memilih repository yang tepat dari daftar
3. Mengatur konfigurasi yang benar untuk website sederhana (Framework Preset: Other)
4. Menekan tombol Deploy dan membaca status prosesnya
5. Menemukan link website publik saya setelah deploy selesai (*.vercel.app)
🟡 PROMPT C-3 · Custom Nama Subdomain
Prompt AI (Custom Domain)
Website saya sudah berhasil deploy di Vercel dan mendapat link default.

Saya ingin mengganti nama subdomain menjadi lebih rapi dan mudah diingat.
Nama yang saya inginkan: [contoh: fin-track-budi.vercel.app]

Tolong panduan saya cara mengubah nama domain di Settings → Domains pada dashboard Vercel.
✅ Part C · Output & Verifikasi Kesiapan
Output yang Diharapkan: Layar menampilkan konfeti selebrasi Vercel "Congratulations!" dan URL hidup `https://nama-proyek.vercel.app`.
Perangkap Pemula: Mengubah opsi build command padahal proyek hanya berisi file HTML statis biasa.
D

Fase D · Update Aplikasi & CI/CD Otomatis

Pembaruan konten aplikasi di laptop dan sinkronisasi otomatis ke website live via git push.

📚 Part A · Teori Pedagogis & Mental Model
💡 Analogi Percetakan Koran Otomatis:

Continuous Deployment (CD) berarti setiap kali wartawan menyetor naskah baru ke meja redaksi (`git push`), mesin cetak otomatis mencetak dan mengirimkan koran baru ke pelanggan tanpa perlu dipicu manual.

🤖 Part B · Master Prompts AI Siap Pakai
🟢 PROMPT D-1 · Update & Auto Re-Deploy
Prompt AI (Update Kode)
Saya sudah berhasil deploy website ke Vercel sebelumnya. Sekarang saya baru saja mengedit file kode saya di laptop dan ingin perubahan ini langsung terbit di website online saya.

Perubahan yang saya buat: [DESKRIPSI PERUBAHAN]

Tolong panduan saya cara mengirim update ini ke GitHub (git add, git commit, git push) dan cara memverifikasi bahwa Vercel sudah otomatis memperbarui websitenya.
✅ Part C · Output & Verifikasi Kesiapan
Output yang Diharapkan: Tab *Deployments* di Vercel menunjukkan build baru berstatus "Ready" dan perubahan langsung tampil saat URL di-refresh.
Perangkap Pemula: Lupa menyimpan file (`Ctrl+S`) di VS Code sebelum menjalankan `git commit`.
E

Fase E · Integrasi Supabase & Environment Variables

Penyimpanan data cloud permanen dan pengamanan kunci API melalui dashboard Vercel.

📚 Part A · Teori Pedagogis & Mental Model
💡 Analogi Brankas Kunci Rahasia:

Kunci rumah tidak boleh digantung di pintu depan. Demikian pula `VITE_SUPABASE_ANON_KEY` harus disimpan di brankas tersembunyi Vercel bernama Environment Variables agar database Anda aman dari pencurian.

Fitur Aplikasi Perlu Supabase? Keterangan
Form Pendaftaran / Login Akun ✅ Wajib Menyimpan identitas pengguna dan sesi login aman.
Catatan / Data Transaksi Keuangan ✅ Wajib Data tetap tersimpan permanen meski ganti perangkat.
Brosur Statis / Profil Portofolio ❌ Tidak Perlu Cukup hosting HTML/CSS/JS statis di Vercel saja.
🤖 Part B · Master Prompts AI Siap Pakai
🟢 PROMPT E-4 (KRITIS!) · Pasang Environment Variables
Prompt AI (Pasang Env Variables di Vercel)
Website saya menggunakan database Supabase dan sudah di-deploy di Vercel. Saya perlu memasang Environment Variables di dashboard Vercel agar koneksi database aktif.

Detail variabel:
- VITE_SUPABASE_URL = [URL SUPABASE KAMU]
- VITE_SUPABASE_ANON_KEY = [KEY SUPABASE KAMU]

Tolong panduan saya:
1. Menemukan menu Settings → Environment Variables di Vercel
2. Menambahkan kedua variabel tersebut
3. Melakukan Redeploy agar variabel aktif di website live
🟡 PROMPT E-5 · Cek Koneksi Data Live
Prompt AI (Verifikasi Koneksi)
Saya sudah memasang Environment Variables di Vercel dan me-redeploy website saya.

Link website Vercel: [LINK VERCEL]
Nama tabel Supabase: [NAMA TABEL]

Tolong panduan saya cara menguji submit form dari website live dan memeriksa data yang masuk di Supabase Table Editor.
✅ Part C · Output & Verifikasi Kesiapan
Output yang Diharapkan: Data transaksi yang diinput dari smartphone langsung muncul di baris tabel Supabase Table Editor secara instan.
Perangkap Pemula: Sudah menambah env var di Vercel tetapi lupa menekan tombol **Redeploy**, sehingga website live masih memakai build versi lama yang belum membaca kunci database.

Prompt Darurat / Pertolongan Pertama Saat Panik

Salin prompt ini ke AI saat layar penuh tulisan merah, website kosong (404), atau bingung kehilangan jejak.

🔴 PROMPT PANIK-1 · Layar Penuh Error Merah
Prompt AI (Emergency Diagnostic)
TOLONG BANTU SAYA! Saya sedang mencoba deploy website ke Vercel tapi layar saya penuh dengan pesan error yang tidak saya mengerti.

Ini pesan error yang muncul di layar saya:
[COPY-PASTE SEMUA PESAN ERROR DI SINI]

Sistem operasi saya: [Windows/Mac/Linux]

Tolong jelaskan apa yang salah dalam bahasa yang sangat sederhana dan berikan solusi perbaikan langkah demi langkah.
🔴 PROMPT PANIK-2 · Website Deploy tapi Blank / 404
Prompt AI (Blank Screen Fix)
Website saya sudah berhasil deploy ke Vercel dan saya punya linknya: [LINK VERCEL]

Tapi ketika saya buka link tersebut, tampilannya putih kosong / error 404.
Kode saya adalah file index.html.

Tolong bantu saya mendiagnosis penyebabnya dan berikan panduan cara memperbaikinya.
