MODUL 01 • Standar Industri

Standar Pesan Commit: Conventional Commits

Pesan commit adalah dokumentasi perjalanan proyek Anda yang akan dibaca oleh tim, klien, atau perekrut di GitHub.

▶ 📋 Format Standar: <tipe>(<cakupan>): <deskripsi ringkas>
feat:
Menambah fitur baru untuk pengguna
fix:
Memperbaiki bug atau galat error
docs:
Perubahan dokumentasi / README
style:
Format CSS, spasi, tanpa ubah logika
refactor:
Rombak struktur kode tanpa ubah fitur
▶ 🤖 Prompt AI Generator Pesan Commit
PROMPT • CONVENTIONAL COMMIT GENERATOR
"Tolong periksa perubahan kode terbaru via 'git diff', lalu buatkan pesan commit profesional dengan format Conventional Commits (feat, fix, docs, refactor, atau style) dalam satu baris yang ringkas dan deskriptif."
MODUL 02 • Etalase Portofolio

Generator README.md Portofolio Profesional

File README.md adalah halaman utama yang pertama kali dilihat siapapun yang membuka repositori GitHub Anda.

▶ 🤖 Prompt AI Pembuat README Lengkap
PROMPT 1 (P6.1) • README.MD PORTFOLIO
"Tolong buatkan file README.md portofolio yang menarik dan profesional untuk proyek ini dalam Bahasa Indonesia. Struktur harus mencakup: 1) Judul & Elevator Pitch 2 kalimat, 2) Fitur Utama dengan ikon emoji, 3) Tech Stack tabel badge, 4) Cara Instalasi & Menjalankan Lokal, 5) Struktur Folder, dan 6) Lisensi."
MODUL 03 • Koneksi Cloud

Hubungkan Repo Lokal ke Remote Origin & Branch main

Mendaftarkan URL target repositori GitHub Cloud sebagai jalur pengiriman bernama origin.

▶ ⚡ Perintah Terminal (CLI Cards)
1. Mendaftarkan Remote
git remote add origin <URL_REPO>
Menyimpan alamat server GitHub tujuan dengan nama alias origin.
2. Standarkan Branch main
git branch -M main
Mengubah nama branch aktif menjadi standar industri modern main.
3. Verifikasi Remote URL
git remote -v
Memastikan URL fetch dan push sudah terpasang dengan benar.
▶ 🤖 Prompt AI Bantuan Setup Remote
PROMPT 2 (P6.2) • SETUP REMOTE & BRANCH MAIN
"Saya baru saja membuat repo kosong di GitHub dengan URL: https://github.com/USERNAME/REPO.git. Tolong daftarkan remote origin tersebut ke repo lokal ini, ubah branch ke 'main', dan verifikasi dengan 'git remote -v'."
MODUL 04 • Unggah Perdana

First Push: Unggah Perdana ke GitHub (-u)

Mengunggah seluruh riwayat commit dari laptop ke GitHub Cloud dan mengunci pelacakan otomatis (upstream tracking).

▶ ⚡ Perintah Terminal (CLI Card)
First Push Upstream
git push -u origin main
Opsi -u (upstream) mengikat branch lokal main ke origin/main selamanya.
▶ 🤖 Prompt AI First Push & Autentikasi
PROMPT 3 (P6.3) • FIRST PUSH UPSTREAM
"Tolong jalankan 'git push -u origin main'. Jika muncul dialog autentikasi GitHub atau Personal Access Token (PAT), jelaskan langkah verifikasinya dengan bahasa yang mudah dipahami."
MODUL 05 • Alur Rutin

Alur Push Rutin Harian 1-Langkah (Daily Sync)

Setelah first push berhasil, alur kerja harian hanya membutuhkan 3 langkah berurutan: Stage → Commit → Push.

▶ ⚡ Perintah Terminal (CLI Card)
Push Cepat Rutin
git push
Cukup ketik git push saja tanpa perlu mengetik nama origin dan branch lagi!
▶ 🤖 Prompt AI Siklus Harian 1-Langkah
PROMPT 4 (P6.4) • SIKLUS DAILY PUSH
"Saya baru saja selesai mengerjakan fitur [NAMA_FITUR]. Tolong jalankan siklus lengkap: 1) 'git add .', 2) Buat commit Conventional Commit yang relevan, dan 3) 'git push' ke GitHub Cloud."
MODUL 06 • Kolaborasi & Resolusi

Sinkronisasi Pembaruan & Resolusi Merge Conflict (Pull)

Mengunduh perubahan terbaru dari GitHub Cloud jika repo diedit lewat web atau oleh rekan tim.

▶ ⚡ Perintah Terminal (CLI Card)
Unduh & Gabung Perubahan
git pull origin main
Mengambil update commit di cloud dan menggabungkannya ke repo lokal.
▶ 🤖 Prompt AI Resolusi Merge Conflict
PROMPT 5 (P6.5) • RESOLUSI MERGE CONFLICT
"Terjadi merge conflict setelah 'git pull'. Tolong periksa tanda penanda conflict (<<<<<<< HEAD vs >>>>>>>) di semua file yang bermasalah, jelaskan perbedaannya, dan bantu saya memilih kode terbaik."
MODUL 07 • Dokter Troubleshooting

Dokter Error Push: Diagnosis & Perbaikan Otomatis

Solusi instan untuk mengatasi galat umum saat push seperti rejected (fetch first), Authentication failed, atau remote origin already exists.

▶ 🤖 Prompt Dokter Diagnosis Error Push
PROMPT 6 (P6.6) • DOKTER ERROR PUSH
"Push ke GitHub gagal dengan pesan error berikut: [PASTE_PESAN_ERROR_TERMINAL_DI_SINI]. Tolong diagnosis penyebabnya (apakah token expired, rejected non-fast-forward, atau remote salah) dan berikan langkah perbaikan terminalnya yang aman."

📊 Cheatsheet Master Perintah GitHub Cloud

Perintah Terminal (CLI) Tingkat Fungsi Utama Tindakan Prompt AI
git remote add origin <URL> Koneksi Mendaftarkan link repo GitHub Cloud sebagai target "Daftarkan remote origin repo GitHub ini"
git branch -M main Koneksi Menstandarkan branch lokal menjadi 'main' "Ubah branch utama ke main"
git push -u origin main First Push Mengunggah perdana & mengunci tracking upstream "Unggah perdana ke GitHub Cloud"
git push Rutin Unggah commit baru secara instan di hari berikutnya "Push commit terbaru ke GitHub"

🏆
Checklist Kelulusan Pertemuan 6 (GitHub Cloud):
  • Repositori GitHub live dapat diakses via URL publik.
  • Branch utama bernama main (bukan master).
  • Memiliki README.md lengkap dengan badge, fitur, dan dokumentasi instalasi.
  • Seluruh riwayat commit rapi berformat Conventional Commits.
  • Tidak ada file rahasia .env atau node_modules yang bocor ke publik.
