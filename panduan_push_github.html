Menyimpan Proyek ke GitHub
100% Berbasis Prompt AI

Sebagai praktisi Vibe Coding, Anda tidak perlu menghafal atau mengetik perintah-perintah terminal yang rumit. Pahami konsep dasarnya di Bagian Teori, lalu cukup salin prompt ke AI Antigravity untuk menyelesaikan praktikumnya.

📖 1. Pelajari Teori Sederhana 🤖 2. Mulai Praktikum (Tinggal Salin Prompt)
BAGIAN 1: TEORI & KONSEP
💡

Mengapa Kita Butuh GitHub?

Memahami peran GitHub dalam kehidupan sehari-hari pembuatan aplikasi

Bayangkan Anda sedang menulis buku berharga di laptop Anda. Jika laptop Anda ketumpahan kopi, rusak, atau hilang, semua tulisan Anda akan lenyap seketika. GitHub adalah lemari brankas online di internet yang menjaga salinan karya Anda tetap aman, bisa dibuka dari laptop manapun, dan bisa dipamerkan ke calon klien atau tempat kerja.

💻

1. Di Laptop Anda

Tempat Anda bekerja bersama AI. Semua file disimpan di harddisk lokal komputer Anda.

☁️

2. Di Cloud GitHub

Salinan online di internet. Berfungsi sebagai cadangan otomatis dan portofolio resmi Anda.

🚀

3. Siap Di-Publish

Setelah ada di GitHub, proyek Anda bisa langsung diubah menjadi website live yang bisa dibuka dari HP.

📖

Kamus Istilah Bahasa Manusia

4 istilah inti yang sering muncul saat bekerja dengan GitHub

🏛️ Repository (Repo) = "Gudang / Folder Proyek di Internet"

Satu halaman khusus di GitHub untuk menampung seluruh file satu aplikasi tertentu.

🏷️ Commit = "Catatan Simpanan / Snapshot"

Memberi label catatan pada hasil kerja terakhir, misalnya: "Tombol login sudah selesai dibuat".

🚚 Push = "Mengunggah / Upload ke Cloud"

Proses mengirimkan hasil simpanan dari laptop ke gudang repository GitHub di internet.

⛔ .gitignore = "Daftar Barang Terlarang"

File pelindung agar password pribadi dan file sampah komputer tidak ikut ter-upload ke internet.

✨ Kunci Vibe Coding: Anda tidak perlu menghafal perintah terminal seperti git init, git remote add, atau git push -u origin main. Cukup pahami artinya secara konsep, dan biarkan AI Antigravity yang menjalankannya untuk Anda!
BAGIAN 2: PRAKTIKUM (PROMPT-BASED)
🎯 Cara Mengikuti Praktikum:
  1. Buka Antigravity IDE tempat proyek Anda terbuka.
  2. Salin salah satu kotak prompt di bawah ini sesuai kebutuhan Anda.
  3. Tempel di ruang chat Antigravity AI, lalu tekan Enter.
  4. Jika Antigravity meminta izin menjalankan perintah di terminal, cukup klik "Allow / Proceed". Selesai!
1

Praktikum 1: Amankan File Rahasia (.gitignore)

Minta AI memastikan tidak ada password atau file sampah yang akan ter-upload

Gunakan prompt ini agar AI membuatkan file pengaman .gitignore secara otomatis sesuai jenis proyek Anda:

🤖 PROMPT 1 — SALIN KE ANTIGRAVITY 
Halo Antigravity, tolong periksa proyek yang sedang saya buka ini.
Saya adalah pemula non-IT dan ingin mempersiapkan proyek ini untuk di-push ke GitHub.

Tolong buatkan file .gitignore yang lengkap dan aman agar file-file sensitif (seperti .env, .env.local, dan folder node_modules) tidak ikut ter-upload ke publik.

Setelah selesai membuat filenya, tolong periksa status git saat ini dan laporkan hasilnya kepada saya dengan bahasa yang sederhana.
2

Praktikum 2: Buat Halaman Penjelasan (README.md)

Minta AI menuliskan deskripsi proyek yang rapi dan profesional

Gunakan prompt ini agar AI membuatkan halaman pembuka (README.md) yang menjelaskan apa fungsi aplikasi Anda kepada orang lain:

🤖 PROMPT 2 — SALIN KE ANTIGRAVITY 
Tolong buatkan file README.md yang menarik dan profesional untuk proyek ini.
Jelaskan secara ringkas:
1. Apa nama dan tujuan aplikasi ini
2. Fitur-fitur utama yang ada di dalamnya
3. Teknologi yang digunakan
4. Cara menjalankan proyek ini di laptop

Tulis dalam Bahasa Indonesia yang rapi dan mudah dibaca oleh orang awam.
3

Praktikum 3: Hubungkan & Push ke GitHub Pertama Kali

Langkah utama mengunggah seluruh proyek ke cloud GitHub

Langkah Kecil di Browser Sebelum Memulai:
Buka github.com/new, beri nama repository Anda, pilih Public, jangan centang apapun, lalu klik tombol hijau "Create repository". Salin URL yang muncul di halaman tersebut.

Setelah mendapatkan URL repo dari GitHub, ganti teks [MASUKKAN URL REPO DI SINI] pada prompt di bawah ini, lalu kirim ke Antigravity:

🤖 PROMPT 3 — SALIN KE ANTIGRAVITY 
Saya sudah membuat repository kosong di GitHub dengan alamat:
[GANTI DENGAN URL REPOSITORY GITHUB ANDA, contoh: https://github.com/username/nama-proyek.git]

Sebagai pemula non-IT, tolong bantu saya melakukan push proyek ini ke GitHub secara otomatis:
1. Simpan (stage & commit) seluruh file proyek saat ini
2. Hubungkan proyek lokal ini ke alamat GitHub tersebut sebagai remote origin
3. Pastikan branch utama bernama main
4. Eksekusi git push ke GitHub

Silakan jalankan perintah terminal yang diperlukan dan beri tahu saya setelah selesai!
4

Praktikum 4: Menyimpan & Upload Perubahan Baru (Harian)

Gunakan setiap kali Anda selesai menambah fitur atau memperbaiki tampilan

Di hari-hari berikutnya, saat Anda sudah selesai melakukan perubahan bersama AI, cukup kirim prompt singkat ini:

🤖 PROMPT 4 — SALIN KE ANTIGRAVITY 
Saya baru saja selesai memperbarui fitur di proyek ini.
Tolong simpan semua perubahan terbaru dengan pesan commit yang rapi dan langsung push ke GitHub saya sekarang.
5

Praktikum 5: Penyelamat Saat Menemui Kendala

Jika ada tulisan merah atau gagal push, biarkan AI yang memperbaikinya

Jika proses push gagal atau terminal menampilkan pesan error, jangan panik. Cukup salin prompt ini:

🤖 PROMPT 5 (TROUBLESHOOTING) — SALIN KE ANTIGRAVITY 
Tolong periksa status git dan remote proyek ini saat ini.
Sepertinya proses push mengalami kendala. Tolong jelaskan kepada saya dalam 1 kalimat apa penyebabnya dengan bahasa yang sangat awam, lalu bantu jalankan perintah perbaikannya secara otomatis agar push berhasil.

🏆 Checkpoint Kelulusan Praktikum:

Buka halaman GitHub Anda di browser, tekan F5. Jika hal-hal ini sudah terlihat, Anda lulus 100%:

  • ✓
    Semua folder dan file proyek Anda sudah muncul rapi di website GitHub.
  • ✓
    Halaman README.md terbaca dengan jelas di bagian bawah daftar file.
  • ✓
    File rahasia .env.local TIDAK muncul di daftar (aman terlindungi).
