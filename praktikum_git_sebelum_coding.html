Praktikum Git Lokal Sebelum Coding

Jaring pengaman wajib dan mesin waktu digital untuk praktisi Vibe Coding. Kuasai inisialisasi, pelacakan perubahan kode, checkpoint save point, dan penyelamatan file rusak buatan AI di komputer lokal.

🎯 Pertemuan
Pertemuan 5 (Blok 2) Durasi: 90 Menit
🛡️ Ruang Lingkup
100% Offline / Komputer Lokal
📦 Prasyarat
Git terinstal di laptop • Antigravity IDE / VS Code
💡
Filosofi Vibe Coding: AI adalah rekan koding yang super cepat namun tidak memiliki tombol undo bawaan yang aman saat merusak fungsi kode. Git Lokal adalah jaring pengaman Anda. Buat commit checkpoint sebelum meminta AI merombak kode, dan Anda bebas bereksperimen tanpa takut kehilangan hasil kerja!
🔍
Pintas: 1. Init & Ignore 2. Status & Diff 3. Add & Commit Checkpoint 4. Emergency Recovery 5. Detektif CCTV 📊 Cheatsheet
MODUL 01 • Tingkat: Dasar (0-10 Menit)

Inisialisasi Repositori & Proteksi File (.gitignore)

Mengubah folder proyek biasa menjadi repositori pelacakan versi resmi dan menetapkan pagar keamanan agar berkas kredensial tidak bocor.

▶ 💡 Analogi Sederhana 12 Tahun
Mengubah folder biasa menjadi "Markas Rahasia" yang dijaga kamera pengawas, serta menempel papan peringatan "Dilarang Masuk" untuk file sampah, cache sistem, & kunci rahasia password (.env).
▶ ⚡ Perintah Terminal (CLI Cards)
Inisialisasi Repo Baru
git init -b main
Membuat folder rahasia .git dan menetapkan branch utama bernama main.
Cek Versi Git
git --version
Memastikan software Git sudah terpasang aktif di sistem komputermu.
Set Identitas Pembuat
git config user.name "Nama Anda"
Mendaftarkan nama pemilik proyek untuk pencatatan riwayat commit.
▶ 🤖 Prompt AI Siap Salin ke Antigravity IDE
PROMPT 1 • SETUP & GITIGNORE AMAN
"Halo AI, tolong inisialisasi repo Git di folder proyek ini dengan branch utama 'main', lalu buatkan file .gitignore standar industri yang aman dari kebocoran file .env, credentials, dan node_modules."
MODUL 02 • Tingkat: Rutin (Audit)

Inspeksi Perubahan (git status & git diff)

Mendeteksi file apa saja yang baru dibuat, diubah, atau dihapus, serta membedah baris kode sebelum dimasukkan ke antrean snapshot.

▶ 💡 Analogi Sederhana 12 Tahun
git status adalah mengecek barang apa saja yang berserakan di meja kerja, sedangkan git diff adalah kaca pembesar untuk melihat kata apa yang kamu hapus (warna merah -) dan kamu tambah (warna hijau +).
▶ ⚡ Perintah Terminal (CLI Cards)
Cek Status File
git status
Melihat file Untracked (merah), Modified (merah), atau Staged (hijau).
Lihat Perbedaan Kode
git diff
Membandingkan baris kode sebelum vs sesudah diedit sebelum masuk ke meja foto.
Lihat Diff File Staged
git diff --staged
Memeriksa baris kode file yang sudah siap di atas meja foto (*staging area*).
▶ 🤖 Prompt AI Siap Salin ke Antigravity IDE
PROMPT 2 • AUDIT PERUBAHAN BERKAS
"Tolong periksa status Git saat ini dengan 'git status' dan jelaskan apa saja baris kode yang baru saja kamu ubah dengan bahasa yang sederhana."
MODUL 03 • Tingkat: Checkpoint (Save Point)

Staging & Commit Checkpoint (Save Point Game)

Memilih berkas ke meja antrean foto (*staging area*) dan mengambil foto simpanan permanen lengkap dengan label deskripsi.

▶ 💡 Analogi Sederhana 12 Tahun
git add adalah menaruh kertas ke atas meja foto studio, sedangkan git commit adalah menjepret foto dan menempelkannya ke album harian resmi lengkap dengan judul keterangan yang rapi.
▶ ⚡ Perintah Terminal (CLI Cards)
Pilih Semua File (Staging)
git add .
Menaruh seluruh perubahan berkas ke meja foto (*Staging Area*).
Simpan Rekaman (Commit)
git commit -m "feat: [deskripsi]"
Menyimpan snapshot permanen dengan pesan standar Conventional Commits.
Buat Checkpoint Save Point
git commit --allow-empty -m "checkpoint: siap rombak"
Membuat Save Point kosong di Git sebelum memberikan tugas besar ke AI.
▶ 🤖 Prompt AI Siap Salin ke Antigravity IDE
PROMPT 3 • STAGING & CONVENTIONAL COMMIT
"Saya sudah selesai mengedit fitur ini. Tolong stage semua file dan buatkan commit message profesional berformat Conventional Commits yang ringkas dan deskriptif."
MODUL 04 • Tingkat: Kritis (Emergency Undo)

Emergency Recovery (Undo & Penyelamatan Kode)

Membatalkan perubahan error, membuang kode rusak buatan AI, atau mengembalikan versi file sehat dari masa lalu.

⚠️
Peringatan Pemulihan: git restore . akan membuang semua editan uncommitted pada file kerja dan mengembalikannya persis seperti saat titik commit terakhir.
▶ 💡 Analogi Sederhana 12 Tahun
Tombol Ctrl + Z tingkat dewa. Memanggil versi file di masa lalu saat AI atau kamu tidak sengaja merusak kode.
▶ ⚡ Perintah Terminal (CLI Cards)
Batalkan File Rusak (Belum Commit)
git restore .
Mengembalikan seluruh file rusak di meja kerja ke kondisi commit terakhir secara instan.
Ambil 1 File Masa Lalu
git restore --source=<HASH> namafile.html
Mengambil kembali versi sehat dari satu file tertentu pada commit masa lalu.
Batalkan Total Commit Terakhir
git reset --hard HEAD~1
⚠️ Menghapus 1 commit terakhir beserta seluruh perubahannya dan memundurkan waktu.
▶ 🤖 Prompt AI Siap Salin ke Antigravity IDE
PROMPT 4 • PEMULIHAN KODE DARURAT (DISCARD)
"Kodingan terakhir ini error dan berantakan. Tolong batalkan semua perubahan yang belum di-commit dan kembalikan file ke kondisi commit terakhir yang sehat."
MODUL 05 • Tingkat: Investigasi (Audit Trail)

Detektif Riwayat (Membaca CCTV Proyek)

Membuka rekaman jejak digital siapa yang mengubah berkas, kapan waktu perubahannya, dan detail ID unik commit hash.

▶ 💡 Analogi Sederhana 12 Tahun
Membuka rekaman CCTV 24 jam untuk mencari tahu siapa yang memindahkan vas bunga dan pada jam berapa. (Tips: Tekan tombol Q di keyboard jika terminal menampilkan log panjang bertanda titik dua).
▶ ⚡ Perintah Terminal (CLI Cards)
Riwayat Ringkas 1 Baris
git log --oneline
Menampilkan daftar commit: 7 huruf hash + judul keterangan commit.
Tampilan Pohon Visual
git log --oneline --graph
Melihat visualisasi garis percabangan (*branch*) dan titik commit.
Lacak Riwayat 1 File Khusus
git log --follow -p index.html
Melihat seluruh jejak perubahan yang pernah dialami oleh satu file sejak awal dibuat.
▶ 🤖 Prompt AI Siap Salin ke Antigravity IDE
PROMPT 5 • RANGKUMAN CAPAIAN DARI LOG
"Tolong periksa riwayat 5 commit terakhir dengan 'git log --oneline -5' dan buatkan ringkasan laporan pekerjaan apa saja yang sudah saya capai hari ini."
🔍
Tidak ditemukan modul atau perintah yang cocok dengan pencarian Anda.

Coba gunakan kata kunci lain seperti: restore, commit, diff, status, log, gitignore

📊 Cheatsheet Master Perintah Git Lokal

🏆
Checklist Kelulusan Pertemuan 5:
  • Folder rahasia .git berhasil terinisialisasi dengan branch utama main.
  • File .gitignore aktif menyaring file rahasia .env dan temporary cache.
  • Memiliki minimal 5 commit bermakna dengan format Conventional Commits.
  • Berhasil mempraktikkan simulasi git restore . saat AI membuat galat kode.
