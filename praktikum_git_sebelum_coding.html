👨‍🏫 Pesan Pengajar: Mengapa Git Lokal Wajib Sebelum Coding?

AI adalah asisten programmer yang super cepat namun tidak memiliki tombol "Ctrl+Z bawaan" yang aman saat membuat kesalahan. Git Lokal adalah Jaring Pengaman (Safety Net) Anda. Dengan membiasakan membuat *checkpoint* simpanan sebelum meminta AI merombak kode, Anda memiliki kekuatan memutar balik waktu kapan pun tanpa takut kehilangan pekerjaan Anda!

01

Modul 1: Inisialisasi Repositori & Proteksi File (.gitignore)

Mengubah folder proyek menjadi repositori Git berizin dan memblokir file rahasia & sampah

Perintah: git init -b main git --version Keamanan: .gitignore (.env, node_modules)
💡 Analogi 12 Tahun: Mengubah folder biasa menjadi "Markas Rahasia" yang dijaga kamera pengawas, serta menempel papan peringatan "Dilarang Masuk" untuk file sampah, cache, & password rahasia.
Inisialisasi Repo Baru
git init -b main
Membuat folder rahasia .git dan menetapkan branch utama bernama main.
Cek Versi Git
git --version
Memastikan Git sudah terinstal dengan benar di komputermu.
🤖 PROMPT AI KE ASISTEN IDE
"Halo AI, tolong inisialisasi repo Git di folder proyek ini dengan branch utama 'main', lalu buatkan file .gitignore standar industri yang aman dari kebocoran file .env dan node_modules."
02

Modul 2: Inspeksi Perubahan (git status & git diff)

Melihat apa saja yang berubah di proyek dan memeriksa detail perbedaan baris kode

Perintah: git status git diff git diff --staged
💡 Analogi 12 Tahun: git status adalah mengecek barang apa saja yang berserakan di meja, sedangkan git diff adalah kaca pembesar untuk melihat kata apa yang kamu hapus (merah -) dan kamu tambah (hijau +).
Cek Status File
git status
Melihat file yang Untracked (merah), Modified (merah), atau Staged (hijau).
Lihat Perbedaan Kode
git diff
Membandingkan baris kode sebelum vs sesudah diedit sebelum masuk ke meja foto.
Lihat Diff File yang Sudah di-Add
git diff --staged
Memeriksa perubahan file yang sudah siap di atas meja foto (*staging area*).
🤖 PROMPT AI KE ASISTEN IDE
"Tolong periksa status Git saat ini dengan 'git status' dan jelaskan apa saja baris kode yang baru saja kamu ubah dengan bahasa yang sederhana."
03

Modul 3: Staging & Commit (Save Point Game)

Memasukkan berkas ke antrean foto dan membekukan snapshot simpanan permanen

Perintah: git add . git commit -m Checkpoint: --allow-empty
💡 Analogi 12 Tahun: git add adalah menaruh kertas di atas meja foto studio, sedangkan git commit adalah menjepret foto dan menempelkannya ke album harian resmi lengkap dengan judul keterangan.
Pilih Semua File (Staging)
git add .
Menaruh seluruh perubahan file ke meja foto (*Staging Area*).
Simpan Rekaman (Commit)
git commit -m "feat: [deskripsi perubahan]"
Menyimpan snapshot permanen dengan pesan standar Conventional Commits.
Buat Checkpoint Save Point
git commit --allow-empty -m "checkpoint: siap minta AI buat fitur X"
Membuat Save Point kosong di Git sebelum memberikan tugas besar ke AI.
🤖 PROMPT AI KE ASISTEN IDE
"Saya sudah selesai mengedit fitur ini. Tolong stage semua file dan buatkan commit message profesional berformat Conventional Commits yang ringkas dan deskriptif."
04

Modul 4: Emergency Recovery (Undo & Penyelamatan Kode)

Membatalkan perubahan error, membuang kode rusak buatan AI, atau mengembalikan snapshot masa lalu

Perintah: git restore . git restore --source git reset --hard
💡 Analogi 12 Tahun: Tombol Ctrl + Z tingkat dewa. Memanggil versi file di masa lalu saat AI atau kamu tidak sengaja merusak kode.
⚠️ Peringatan Penting: git restore . akan mengembalikan seluruh file uncommitted ke kondisi commit terakhir secara instan.
Batalkan File Rusak (Belum Commit)
git restore .
Mengembalikan seluruh file rusak di meja kerja ke kondisi commit terakhir secara instan.
Ambil 1 File Masa Lalu (Sudah Commit)
git restore --source=<HASH_COMMIT> namafile.html
Mengambil kembali versi sehat dari satu file tertentu pada commit masa lalu.
Batalkan Total Commit Terakhir
git reset --hard HEAD~1
⚠️ Menghapus 1 commit terakhir beserta seluruh perubahannya dan memundurkan waktu.
🤖 PROMPT AI KE ASISTEN IDE
"Kodingan terakhir ini error dan berantakan. Tolong batalkan semua perubahan yang belum di-commit dan kembalikan file ke kondisi commit terakhir yang sehat."
05

Modul 5: Detektif Riwayat (Membaca CCTV Proyek)

Melihat rekaman riwayat snapshot, garis percabangan, dan jejak kelahiran satu file

Perintah: git log --oneline git log --graph git log --follow -p
💡 Analogi 12 Tahun: Membuka rekaman CCTV 24 jam untuk mencari tahu siapa yang memindahkan vas bunga dan pada jam berapa. (Tekan Q di keyboard untuk keluar dari log panjang).
Riwayat Ringkas Satu Baris
git log --oneline
Menampilkan daftar commit: 7 huruf kode hash + judul pesan commit.
Tampilan Pohon Visual
git log --oneline --graph
Melihat visualisasi garis percabangan (*branch*) dan titik commit.
Lacak Riwayat Satu File Khusus
git log --follow -p index.html
Melihat seluruh jejak perubahan yang pernah dialami oleh satu file sejak awal lahir.
🤖 PROMPT AI KE ASISTEN IDE
"Tolong periksa riwayat 5 commit terakhir dengan 'git log --oneline -5' dan buatkan ringkasan laporan pekerjaan apa saja yang sudah saya capai hari ini."
🔍
Tidak ditemukan modul atau perintah yang cocok dengan pencarian Anda.

Coba gunakan kata kunci lain seperti: restore, commit, diff, status, log, gitignore
