🛡️ Product Requirements Document (PRD) — Modul Pertemuan 12

Keamanan Data & Validasi Input:
Benteng Pertahanan Aplikasi Bisnis bagi Vibe Coder

Panduan praktikum terpadu 90 menit bagi pemula non-IT dan pemilik bisnis untuk membangun form aplikasi web yang aman, anti-injeksi, kebal spam, mengenkripsi password dengan standar industri, serta mampu melakukan audit mandiri menggunakan AI Agent.

⏱️ Durasi: 90 Menit Terstruktur
💂 Analogi: Satpam Pintu Toko & Brankas
🔐 Standar: Bcrypt & Parameterized Query
🤖 AI Audit: Prompt "Hacker Baik"
🗺️ Peta 90 Menit 🧠 Teori Satpam & 4 Pilar 💻 Lab 1: 5 Form Standar 🟡 Lab 2: Adaptasi Bisnis & Audit 📊 Evaluasi & Kamus Istilah
🗺️

Peta Perjalanan Belajar (90 Menit)

Struktur alokasi waktu dan target kompetensi praktikum.

Segmen Aktivitas Utama Durasi Output / Hasil Nyata
🧠 Teori Singkat Konsep keamanan data & 4 pilar proteksi dengan analogi toko fisik 20 menit Mental model "Jangan Percaya Input Pengguna"

🛡️ Mental Model: Arsitektur Satpam Validasi Data

[Pengguna / Calon Hacker] │ ▼ ┌─────────────────────────────────────────────────────────────┐ │ 🏪 FORM INPUT (Pintu Toko) │ │ - Nama, Email, Nomor HP, Password, Pesan, Nominal Transaksi │ └──────────────────────────────┬──────────────────────────────┘ │ (Data Masuk) ▼ ┌─────────────────────────────────────────────────────────────┐ │ 💂 SATPAM VALIDASI & SANITASI (Validation Layer) │ │ 1. Cek Tipe Data & Format (Email regex, digit HP, min length)│ │ 2. Sanitasi Karakter Jahat (Hapus <script>, escape HTML) │ │ 3. Rate Limiter & Anti-Spam (Lockout 5x login, Math CAPTCHA)│ │ 4. Hashing Password (Bcrypt kode acak satu arah) │ └──────────────────────────────┬──────────────────────────────┘ │ (Data Bersih & Aman) ▼ ┌─────────────────────────────────────────────────────────────┐ │ 🏦 DATABASE / LOCALSTORAGE (Brankas Toko) │ │ - Parameterized Query (Bebas SQL Injection) │ │ - Password Terenkripsi (Tidak bisa dibaca jika bocor) │ └─────────────────────────────────────────────────────────────┘

Prinsip Utama: Selalu validasi di dua sisi (Klien + Server). Jangan pernah menyimpan password dalam bentuk teks biasa (plaintext) dan jangan biarkan teks pengguna masuk ke database tanpa sanitasi.

🧠

Bagian 1 · Teori Pedagogis (20 Menit)

Memahami 4 pilar keamanan web tanpa pusing menghafal rumus teknis.

🏪 Analogi Toko Fisik vs Toko Online:

• Pintu masuk toko = Form input (pendaftaran, order, login)
• Pelanggan yang masuk = Data yang diisi pengguna
• Satpam di pintu = Validasi input & sanitasi
• Brankas toko = Database Supabase / penyimpanan data
Tanpa satpam, siapa saja bisa menyusup dan merusak isi brankas bisnismu!

Pilar 1

Validasi Form Input

"Satpam Periksa KTP": Memastikan email berformat @ dan domain, nomor HP hanya angka Indonesia (08/62), dan nama tidak berisi simbol berbahaya agar database tidak penuh data sampah.

Pilar 2

Enkripsi Password

"Gembok Kode Acak": Password tidak boleh disimpan apa adanya (toko123), melainkan di-hash menjadi kode acak Bcrypt ($2b$10$Xk9...) sehingga aman jika database diretas.

Pilar 3

Proteksi SQLi & XSS

"Cegah Celah Tersembunyi": Mencegah injeksi perintah database palsu (' OR '1'='1) via Parameterized Query, dan membersihkan script berbahaya (<script>) sebelum dirender ke layar.

Pilar 4

Validasi Transaksi

"Cek Ganda Sebelum Bayar": Menolak harga nol/negatif, membatasi jumlah pesanan tidak melebihi stok, dan memverifikasi upload bukti bayar hanya file gambar asli (JPG/PNG < 2MB).

Bagian 2 · Praktikum 1: 5 Form Standar Siap Salin (25 Menit)

Salin prompt ke AI Assistant di Antigravity IDE, jalankan preview, dan uji validasinya.

1A

Form Pendaftaran Pelanggan dengan Validasi Lengkap

🎯 Level: Dasar • ⏳ 5 Menit
🤖 Master Prompt AI (Salin ke Antigravity IDE)
📝 PROMPT 1A — REGISTRATION VALIDATOR 
Buatkan saya form pendaftaran pelanggan untuk toko online dengan HTML dan JavaScript.
Form ini harus memiliki validasi untuk:
- Nama lengkap: wajib diisi, minimal 3 karakter, hanya huruf dan spasi
- Email: wajib diisi, format email yang valid (harus ada @ dan domain)
- Nomor HP: wajib diisi, hanya angka, panjang 10-13 digit (format Indonesia)
- Password: minimal 8 karakter, harus mengandung huruf besar, huruf kecil, dan angka
- Konfirmasi password: harus sama persis dengan password

Tampilkan pesan error yang jelas dan ramah dalam Bahasa Indonesia di bawah setiap input.
Buat tampilannya modern dan bersih dengan CSS bernuansa biru tua dan putih.
✅ Yang Harus Terjadi (Expected Result)

Saat klik daftar tanpa mengisi email atau menulis email tanpa @, muncul teks merah ramah di bawah input dan form menolak submit.

⚠️ Coba Uji Sendiri (Refleksi)

Ketik konfirmasi password yang berbeda 1 huruf. Pastikan sistem mendeteksi ketidakcocokan secara instan.

1B

Form Login dengan Proteksi Brute-Force & Pesan Aman

🎯 Level: Menengah • ⏳ 5 Menit
🤖 Master Prompt AI (Salin ke Antigravity IDE)
📝 PROMPT 1B — SECURE LOGIN 
Tambahkan halaman login ke proyek toko online saya dengan standar keamanan berikut:
- Form login dengan field Email dan Password
- Batasi percobaan login maksimal 5 kali (jika gagal 5 kali, kunci form selama 15 menit dengan countdown timer)
- Gunakan pesan error GENERIK: tampilkan "Email atau password tidak valid" (jangan beritahu penyerang apakah email atau password-nya yang salah)
- Tambahkan tombol toggle mata "Tampilkan / Sembunyikan Password"
- Validasi: email wajib terisi format valid, password tidak boleh kosong

Terapkan antarmuka berbahasa Indonesia yang ramah pengguna.
✅ Kunci Keamanan Profesional

Pesan error yang tidak spesifik mencegah hacker menebak apakah email tertentu sudah terdaftar atau belum (mencegah *User Enumeration*).

⚠️ Simulasi Brute Force

Klik tombol login 5 kali berturut-turut dengan data salah. Form harus langsung terkunci dengan pesan hitung mundur.

1C

Form Pemesanan dengan Validasi Transaksi & Live Summary

🎯 Level: Menengah • ⏳ 5 Menit
🤖 Master Prompt AI (Salin ke Antigravity IDE)
📝 PROMPT 1C — ORDER & TRANSACTION VALIDATOR 
Buatkan form pemesanan produk untuk toko online saya dengan validasi transaksi:
- Pilihan Produk: dropdown dengan 3 opsi produk & harga simulasi
- Jumlah Pembelian: hanya angka positif bulat, minimal 1, maksimal stok (maks 50)
- Nama Penerima: wajib diisi, minimal 3 karakter
- Alamat Pengiriman: wajib diisi, minimal 10 karakter
- Nomor HP Penerima: format valid Indonesia (diawali 08 atau +62, panjang 10-13 digit)
- Catatan Khusus: opsional, dibatasi maksimal 200 karakter

Tampilkan ringkasan pesanan otomatis (Total Harga = Jumlah x Harga Produk) di samping form.
Tampilkan semua pesan validasi dalam Bahasa Indonesia.
✅ Integritas Data Keuangan

Pengguna tidak bisa memasukkan jumlah `-5` atau `0`, sehingga total tagihan kalkulasi tidak pernah bernilai negatif atau nol.

⚠️ Sanitasi Catatan

Kolom catatan membatasi panjang teks sehingga tidak bisa digunakan untuk membanjiri memori database.

1D

Form Kontak dengan Anti-Spam (Math CAPTCHA)

🎯 Level: Menengah • ⏳ 5 Menit
🤖 Master Prompt AI (Salin ke Antigravity IDE)
📝 PROMPT 1D — ANTI-SPAM CONTACT FORM 
Buatkan form kontak pengaduan pelanggan untuk website bisnis saya dengan:
- Nama: wajib diisi, minimal 3 karakter
- Email: wajib diisi format valid
- Subjek: wajib diisi, minimal 5 karakter
- Isi Pesan: wajib diisi minimal 20 karakter, maksimal 500 karakter
- Tambahkan penghitung karakter real-time ("X / 500 karakter") di bawah textarea pesan
- Tambahkan proteksi Math CAPTCHA sederhana acak (contoh: "Berapa 4 + 7?") yang berubah tiap kali di-load
- Form tidak boleh terkirim jika jawaban CAPTCHA salah

Gunakan antarmuka yang bersih, responsif, dan ramah pengguna.
✅ Manfaat CAPTCHA

Mencegah robot spammer mengirim ribuan pesan otomatis ke inbox email pemilik bisnis.

⚠️ Live Counter

Memberi feedback visual langsung kepada pengguna sehingga mereka tahu sisa batas karakter yang diizinkan.

1E

Halaman Pembayaran Sederhana dengan Filter File Upload

🎯 Level: Mahir • ⏳ 5 Menit
🤖 Master Prompt AI (Salin ke Antigravity IDE)
📝 PROMPT 1E — PAYMENT & FILE FILTER 
Buatkan halaman ringkasan dan konfirmasi pembayaran toko online dengan validasi:
- Pilihan Metode Pembayaran: Transfer Bank, QRIS, atau COD
- Jika Transfer Bank dipilih: tampilkan upload bukti transfer (validasi ketat: HANYA format JPG/PNG dan ukuran maksimal 2MB)
- Jika QRIS dipilih: tampilkan simulasi QR Code dan petunjuk bayar
- Jika COD dipilih: tampilkan konfirmasi alamat pengiriman
- Tambahkan checkbox wajib: "Saya telah membaca dan menyetujui syarat & ketentuan pembelian"
- Tambahkan dialog modal konfirmasi sebelum submit: "Apakah Anda yakin ingin memproses pesanan senilai [Total]?"

Gunakan pesan peringatan yang ramah dan jelas dalam Bahasa Indonesia.
✅ Proteksi File Upload

Menolak file .exe, .php, atau file raksasa di atas 2MB yang bisa membahayakan server hosting.

⚠️ Konfirmasi Transaksi Ganda

Mencegah pelanggan tidak sengaja menekan tombol bayar dua kali (double charge).

Bagian 3 · Praktikum 2: Adaptasi Bisnis & Audit Keamanan (25 Menit)

Sesuaikan prompt dengan kebutuhan toko aslimu, lalu uji kekuatannya menggunakan prompt Hacker Baik.

2A

Template Modifikasi Form Bisnis Mandiri

🎯 Kustomisasi Bisnis
📝 Template Prompt (Ganti bagian dalam tanda kurung)
⚙️ TEMPLATE PROMPT BISNIS 
Buatkan form [JENIS FORM: misal Pemesanan Katering / Reservasi Meja / Pembelian Produk]
untuk bisnis "[NAMA BISNIS KAMU]" yang bergerak di bidang [BIDANG BISNIS].

Form ini harus memvalidasi data berikut:
- [Field 1]: wajib diisi, aturan validasi [aturan]
- [Field 2]: wajib diisi, aturan validasi [aturan]
- [Field 3]: opsional / wajib, aturan validasi [aturan]

Terapkan standar keamanan:
- Validasi ketat format email & nomor HP Indonesia (+62/08)
- Sanitasi input untuk mencegah script jahat
- Batasi jumlah karakter teks dan ukuran file upload
- Dialog konfirmasi sebelum submit pesanan

Nuansa warna: [WARNA UTAMA] dan [WARNA SEKUNDER].
Bahasa: Indonesia ramah pengguna.
Contoh Nyata (Bisnis Katering "Dapur Bu Sari"):

Validasi tanggal acara minimal 7 hari dari hari ini (agar sempat masak), jumlah tamu minimal 50 porsi, dan budget per orang minimal Rp 25.000. Aturan bisnis ini langsung diterjemahkan menjadi validasi kode oleh AI!

2B

Audit Keamanan dengan Prompt "Hacker Baik" (AI Security Auditor)

🛡️ Security Simulation
🤖 Master Prompt Audit Keamanan (Jalankan setelah membuat form)
🕵️ PROMPT AUDIT HACKER BAIK 
Saya sudah membuat kode form di atas. Sekarang berperanlah sebagai Ethical Hacker & Security Auditor. Tolong:

1. Simulasikan 5 cara pengguna jahat / hacker mencoba menyalahgunakan form ini (misal: input negatif, tag script XSS, SQL injection palsu, flood klik, file berbahaya).
2. Untuk setiap skenario, jelaskan apakah validasi yang ada saat ini sudah berhasil mencegahnya atau masih tembus.
3. Jika masih ada celah keamanan, berikan perbaikan kodenya secara langsung.
4. Buatkan laporan ringkas:
   - ✅ Form ini sudah aman dari: [Daftar proteksi yang berhasil]
   - ⚠️ Rekomendasi peningkatan: [Daftar saran keamanan lanjutan]

Sampaikan seluruh penjelasan dalam bahasa yang mudah dipahami oleh pemilik bisnis non-teknis.
2C

SOP Tanggap Darurat & Checklist Bulanan

📋 SOP Operasional
🤖 Prompt SOP Keamanan Bisnis Online
📅 PROMPT SOP BULANAN 
Sebagai pemilik bisnis online non-teknis, buatkan saya:
1. Checklist keamanan bulanan yang bisa saya lakukan sendiri tanpa coding untuk website saya
2. Tanda-tanda bahaya (red flags) jika website terindikasi sedang diserang atau bocor
3. Langkah pertama yang harus saya lakukan jika mencurigai ada kebocoran data pelanggan
4. Rekomendasi tools gratis untuk mengecek kesehatan keamanan website

Format dalam bentuk panduan ringkas siap cetak.

📚 Kamus Istilah Keamanan (Bahasa Manusia)

Istilah Teknis Artinya untuk Pemilik Bisnis & Vibe Coder
Validasi Input Proses pemeriksaan apakah data yang diisi pembeli sudah lengkap dan sesuai format yang benar sebelum diproses.
Enkripsi / Bcrypt Hashing Mengubah password rahasia menjadi kode acak satu arah sehingga tidak bisa dibaca manusia walaupun data dicuri.
SQL Injection (SQLi) Trik penjahat yang menyelipkan teks perintah database palsu (misal ' OR 1=1) di form login agar bisa masuk tanpa password.
Cross-Site Scripting (XSS) Trik penjahat yang menyisipkan kode script jahat di kolom komentar atau ulasan agar menjebak pembeli lain yang membuka halaman.
Sanitasi Input Proses mencuci/membersihkan karakter berbahaya (seperti tanda kurung siku < >) agar teks tampil murni sebagai teks biasa.
Math CAPTCHA Pertanyaan logika/hitung sederhana yang hanya bisa dijawab manusia untuk mencegah robot spammer membanjiri website.
Parameterized Query Teknik baku database untuk memisahkan antara perintah SQL dengan data pengguna sehingga kebal dari SQL Injection.

🛡️ Senjata Wajib: Master Prompt Keamanan Standar untuk Segala Form

Simpan dan tempelkan instruksi ini setiap kali kamu meminta AI membuat form baru:

⚡ UNIVERSAL FORM SECURITY PROMPT 
Buatkan [JENIS FORM] dengan standar keamanan wajib berikut:
1. Validasi semua field sebelum form disubmit (tampilkan pesan error merah yang ramah dalam Bahasa Indonesia)
2. Sanitasi input teks untuk mencegah serangan XSS dan karakter berbahaya
3. Pesan error login/auth bersifat generik (tidak membocorkan apakah email atau password yang salah)
4. Password (jika ada) harus memenuhi minimal 8 karakter dan di-hash aman
5. Batasi format upload hanya file gambar asli (JPG/PNG maks 2MB)
6. Tambahkan dialog konfirmasi sebelum mengeksekusi aksi penting
7. Berikan komentar di setiap baris kode yang menjelaskan fungsi keamanannya
