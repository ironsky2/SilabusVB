📱 MODUL PRAKTIKUM MOBILE VIBE CODING

Membangun Aplikasi Android & Web dengan Flutter + Supabase via Antigravity IDE

Panduan langkah-demi-langkah bagi profesional non-IT untuk merancang, meng-generate UI responsif, menghubungkan database cloud real-time, dan menguji aplikasi langsung di smartphone Android tanpa menulis kode manual dari nol.

🎯 Target: Profesional Non-IT / Pemula
🤖 AI Agent: Antigravity IDE
⏱️ Estimasi: 3–4 Jam
📦 Output: App Android (.apk) & Web Chrome
💡 Mental Model: Apa itu Vibe Coding Flutter?

Vibe Coding bukanlah menghafal ribuan baris sintaksis Dart atau widget Flutter. Anda bertindak sebagai Arsitek & Manajer Produk: Anda menentukan kebutuhan bisnis dan alur visual dalam bahasa natural, sementara Antigravity AI Agent bertindak sebagai developer pribadi 24 jam yang menulis kode, memperbaiki bug, dan menghubungkan backend Supabase secara otomatis.

Bagian 4: Setup Project Flutter via Prompting

Part B · Master Prompts AI
🤖 PROMPT 4.1 — Struktur Folder Arsitektur Bersih
Saya baru membuat project Flutter bernama my_app. Tolong atur struktur folder yang rapi dan modular di dalam lib/ untuk aplikasi CRUD + Supabase: - lib/screens/ (untuk halaman UI utama) - lib/widgets/ (untuk komponen UI reusable) - lib/services/ (untuk koneksi API dan Supabase service) - lib/models/ (untuk struktur data model) - lib/config/ (untuk file konfigurasi global) Buatkan file placeholder di setiap folder agar struktur terlihat jelas dan jelaskan fungsinya.

Tambahkan package Supabase ke project Flutter saya: 1. Update pubspec.yaml dengan dependensi 'supabase_flutter: ^2.8.0' 2. Setup inisialisasi awal di lib/main.dart dengan placeholder URL dan anonKey 3. Pastikan MaterialApp membungkus SplashScreen sebagai initial route

Fase 6 · Database Cloud

Bagian 6: Konfigurasi Database Supabase

Menghubungkan aplikasi Flutter ke tabel PostgreSQL Supabase melalui arsitektur Service Layer yang bersih.

Part A · Schema Tabel SQL di Supabase

Jalankan perintah SQL berikut di menu SQL Editor dashboard Supabase Anda:

SUPABASE SQL EDITOR
-- Buat tabel items untuk menyimpan data aplikasi CREATE TABLE public.items ( id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY, judul TEXT NOT NULL, deskripsi TEXT, created_at TIMESTAMPTZ DEFAULT NOW(), user_id UUID REFERENCES auth.users(id) ON DELETE CASCADE ); -- Aktifkan Row Level Security (RLS) ALTER TABLE public.items ENABLE ROW LEVEL SECURITY; -- Kebijakan Akses: Pengguna hanya dapat mengelola datanya sendiri CREATE POLICY "Users can manage their own items" ON public.items FOR ALL USING (auth.uid() = user_id) WITH CHECK (auth.uid() = user_id);
Part B · Master Prompt Service Layer
🤖 PROMPT 6.1 — Supabase DataService (lib/services/data_service.dart)
Buatkan file lib/services/data_service.dart dengan class DataService: Gunakan `Supabase.instance.client` untuk membuat 4 fungsi CRUD lengkap: 1. getAllItems() -> mengambil semua data dari tabel 'items', urutkan created_at descending, return List<Map<String, dynamic>> 2. addItem(String judul, String deskripsi) -> insert record baru dengan menyertakan user_id yang sedang login 3. updateItem(int id, String judul, String deskripsi) -> update judul dan deskripsi berdasarkan id 4. deleteItem(int id) -> hapus item dari tabel berdasarkan id Semua fungsi harus memiliki penanganan blok try-catch dan logging error yang jelas.

Bagian 7: Implementasi Fitur CRUD Interaktif

Menghubungkan halaman antarmuka visual ke fungsi database untuk menampilkan list, menambah, mengedit, dan menghapus item.

🤖 PROMPT 7.1 — Menampilkan Data List Realtime
Update lib/screens/data_list_screen.dart: - Ubah menjadi StatefulWidget yang memanggil DataService().getAllItems() saat initState() - Tampilkan CircularProgressIndicator saat memuat data - Tampilkan Empty State ilustrasi jika data masih kosong (0 item) - Gunakan ListView.builder untuk merender Card setiap item: * Judul item (Bold font) * Deskripsi item & tanggal dibuat * Tombol Edit (icon pensil oranye) -> buka EditItemScreen * Tombol Hapus (icon sampah merah) -> tampilkan dialog konfirmasi sebelum hapus - Sediakan RefreshIndicator agar pengguna bisa tarik layar ke bawah (pull-to-refresh)

Fase 8 · Keamanan & Akun

Bagian 8: Autentikasi Pengguna Supabase Auth

Menerapkan login, register, proteksi rute (Auth Guard), serta manajemen sesi pengguna.

Part B · Master Prompts Auth Service & Guard
🤖 PROMPT 8.1 — AuthService (lib/services/auth_service.dart)
Buatkan file lib/services/auth_service.dart dengan class AuthService: - signUp(String email, String password): mendaftarkan akun baru menggunakan supabase.auth.signUp() - signIn(String email, String password): login akun menggunakan supabase.auth.signInWithPassword() - signOut(): keluar akun menggunakan supabase.auth.signOut() - currentUser: getter untuk mendapatkan data user yang sedang aktif - isLoggedIn: bool getter untuk mengecek apakah sesi user masih aktif
🤖 PROMPT 8.2 — Auth Guard di Splash Screen
Update SplashScreen di lib/screens/splash_screen.dart: Setelah delay 2 detik, lakukan pengecekan sesi dengan AuthService().isLoggedIn: - Jika user SUDAH login -> langsung navigasi ke HomeScreen - Jika user BELUM login -> navigasi ke LoginScreen Pastikan user tidak bisa kembali ke Splash Screen dengan tombol back (gunakan Navigator.pushReplacement).
Fase 9 · Uji Coba & Eksekusi

Bagian 9: Menjalankan Aplikasi di HP Android & Chrome

Langkah menghubungkan smartphone fisik melalui USB Debugging atau menjalankan simulasi cepat di Web Chrome.

Part A · Langkah Aktivasi USB Debugging Android
  1. Buka Pengaturan (Settings) → Tentang Ponsel (About Phone).
  2. Ketuk Nomor Build (Build Number) sebanyak 7 kali hingga muncul pesan "Anda sekarang adalah developer!".
  3. Masuk ke Pengaturan Tambahan → Opsi Pengembang (Developer Options) → Aktifkan USB Debugging.
  4. Hubungkan HP ke komputer dengan kabel data USB. Pada layar HP, pilih Transfer File (MTP) dan ketuk "Izinkan Selalu" pada pop-up otorisasi debug komputer.
Part B · Perintah Eksekusi di Terminal
TERMINAL ANTIGRAVITY IDE
# 1. Cek daftar perangkat HP yang terhubung adb devices # 2. Jalankan aplikasi langsung ke HP Android flutter run # 3. ATAU jalankan di Browser Web Chrome flutter run -d chrome
⚡ Tombol Rahasia Selama Aplikasi Berjalan di Terminal

Tekan r pada keyboard terminal untuk Hot Reload (update tampilan instan dalam < 1 detik).
Tekan R (huruf besar) untuk Hot Restart (mengulang aplikasi dari awal).
Tekan q untuk keluar / menghentikan sesi.

Fase 11 · Solusi Masalah

Bagian 11: Diagnosa Masalah & Troubleshooting

Jangan panik saat melihat error di terminal. Cukup salin seluruh teks pesan error dan kirimkan ke chat AI Antigravity.

Part A · 4 Kasus Masalah Paling Sering Terjadi
1. Permission Internet Belum Diatur
Aplikasi crash saat memanggil Supabase di HP Android asli.
Solusi: Pastikan tag <uses-permission android:name="android.permission.INTERNET"/> ada di android/app/src/main/AndroidManifest.xml.
2. Policy RLS Supabase Mengunci Query
Data berhasil disimpan di dashboard Supabase tapi tidak muncul di aplikasi Flutter.
Solusi: Periksa tab Authentication & RLS di Supabase, pastikan ada Policy SELECT yang aktif untuk role authenticated.
🤖 PROMPT — Diagnosa Otomatis Error ke AI
Saya mengalami error saat menjalankan aplikasi Flutter ke HP Android: [PASTE SELURUH PESAN ERROR DARI TERMINAL DI SINI] Tolong jelaskan akar penyebab masalahnya dengan bahasa sederhana, dan langsung perbaiki file kode yang bermasalah.
